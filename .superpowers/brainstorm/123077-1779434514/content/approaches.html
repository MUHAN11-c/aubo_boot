两种重构方案

目标：无遮挡 + 统一主题 + vision/latte CSS 分离

A

最小分离修复

不改架构，只修问题点。给 latte 复制一份独立的基础样式（从 vision_grasp 中剥离约 300 行布局代码），删除 connection-footer，修 z-index 冲突。

优点

  • 改动量小（~200 行变更）
  • 风险低
  • 快速见效

缺点

  • 两份重复的布局代码（vision + latte 各一份）
  • 设计令牌仍然碎片化（5 个 :root 各自定义）
  • 后续改主题需要改多处
B

提取共享层 + 页面独立

新建 2 个共享文件（tokens.css + layout-base.css），vision 和 latte 各自独立加载，无交叉依赖。共享层只放变量和布局基类。

优点

  • 单一数据源：所有颜色/间距/阴影在一处定义
  • vision 和 latte 完全独立，各自只加载需要的样式
  • 后续改主题只改一个文件
  • 总 CSS 量减少（消除重复定义）

缺点

  • 改动量中等（~500 行变更，涉及 6 个 HTML + 5 个 CSS）
  • 需要仔细验证每个页面

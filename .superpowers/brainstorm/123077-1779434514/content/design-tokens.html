设计第一部分：统一设计令牌 tokens.css

所有页面的单一数据源。合并 5 个 :root 定义，统一变量命名。

tokens.css 内容 (~50 行)
/* tokens.css — 全站唯一设计令牌源 */
:root {
  /* 背景 */
  --bg: #fafbfc;
  --bg-elevated: #ffffff;
  --bg-muted: #f5f6f8;

  /* 边框 */
  --border: #e2e6ed;
  --border-strong: #d1d6df;

  /* 文字 */
  --text: #171b23;
  --text-secondary: #4b5565;
  --text-muted: #8b95a6;

  /* 主题色 */
  --accent: #2563eb;
  --accent-hover: #1d4ed8;
  --accent-soft: rgba(37,99,235,0.07);

  /* 语义色 */
  --ok: #16a34a;
  --warn: #d97706;
  --err: #dc2626;

  /* 阴影 */
  --shadow-sm: 0 1px 3px rgba(15,23,42,0.06);
  --shadow-md: 0 6px 20px rgba(15,23,42,0.09);

}

命名统一对照

旧 (混乱)新 (统一)影响文件

--panel (home/settings)--bg-elevatedhome.css, settings_panel.css
--panel-muted (home/vision)--bg-mutedhome.css, vision_grasp_panel.css

--text-muted (ivg_base)--text-muted ✅保持不变

目标架构 (分层清晰)
┌─────────────────────────────────────┐
│ Layer 4: 渲染 / 业务                │
│ 所有页面统一走 RosManager (ros.js)  │
│ debug │ vision │ latte │ status_bar│
└──────────────┬──────────────────────┘
               │ 唯一入口
               ▼
┌─────────────────────────────────────┐
│ Layer 3: 统一 API 抽象层            │
│ RosManager (ros.js)                 │
│ • 连接生命周期                      │
│ • 重连状态机                        │
│ • subscribe/publish/callService     │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│ Layer 2: 调度 / 通信路由层          │
│ TransportHub (单一调度中心)          │
│ • 适配器注册 & 健康检查              │
│ • 模式切换 & 订阅迁移 (FIFO)        │
│ • TopicRouter + ServiceRouter      │
│ • 事件广播 (modechange/bridgechg)   │
└──────┬──────────────────┬───────────┘
       │                  │
       ▼                  ▼

│ Layer 0:    │   │ Layer 0:     │
│ 原始传输层  │   │ 原始传输层   │

│ (JSON)      │   │ (CDR binary) │
└─────────────┘   └──────────────┘

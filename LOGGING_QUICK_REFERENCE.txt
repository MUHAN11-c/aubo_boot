┌──────────────────────────────────────────────────────────────────────┐
│ ⚠️  常见错误和解决方法                                               │
└──────────────────────────────────────────────────────────────────────┘

  ❌ "视觉估计服务 /estimate_pose 不可用"
     → 启动: ros2 run visual_pose_estimation_python main

  ⚠ "视觉估计未检测到目标"
     → 检查工件位置、光照、模板

  ❌ "第X段失败: Y移动"
     → 检查关节限位、调整速度参数

  ⚠ "循环抓取已在运行中"
     → 先停止: ros2 service call /loop_grasp_control ...

  ✗ "步骤 X 失败"
     → 查看详细错误信息，检查机械臂状态

│ 💡 调试技巧                                                          │

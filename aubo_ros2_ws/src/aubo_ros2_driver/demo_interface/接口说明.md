# demo_interface 接口说明

`demo_interface` 包定义了奥博机械臂演示系统所用的 ROS 2 消息（msg）和服务（srv）接口，分为三类：
- **状态消息** — 推送机械臂及 IO 实时状态
- **运动控制服务** — 控制机械臂运动（轨迹规划 / 直线运动 / 关节控制）
- **配置与操作服务** — 设置参数、快换、IO 读写等

---

## 一、消息（msg）

### 1. RobotStatus — 机械臂状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `header` | `std_msgs/Header` | 标准消息头（时间戳 + 坐标系帧ID） |
| `is_online` | `bool` | 机器人在线状态（true=在线，false=离线） |
| `enable` | `bool` | 机器人使能状态（true=已使能，false=未使能） |
| `in_motion` | `bool` | 机器人运动状态（true=运动中，false=静止） |
| `planning_status` | `string` | MoveIt2 规划状态（idle / planning / executing / error） |
| `joint_position_rad` | `float64[6]` | 6 关节角度（弧度） |
| `joint_position_deg` | `float64[6]` | 6 关节角度（度） |
| `cartesian_position` | `geometry_msgs/Pose` | TCP 位姿（位置 m + 四元数姿态） |
| `cartesian_position_xyz` | `geometry_msgs/Point` | TCP 位置（x, y, z 单位 m） |
| `cartesian_rpy` | `geometry_msgs/Vector3` | TCP 姿态（欧拉角 roll/pitch/yaw 单位 rad） |

### 2. ToolIOStatus — 工具端 IO

| 字段 | 类型 | 说明 |
|------|------|------|
| `digital_inputs` | `bool[]` | 数字量输入（布尔数组） |
| `digital_outputs` | `bool[]` | 数字量输出（布尔数组） |
| `analog_inputs` | `float32[]` | 模拟量输入（电压/电流值数组） |
| `analog_outputs` | `float32[]` | 模拟量输出（电压/电流值数组） |

### 3. RobotIOStatus — 机器人整体 IO

| 字段 | 类型 | 说明 |
|------|------|------|
| `header` | `std_msgs/Header` | 标准消息头 |
| `digital_inputs` | `bool[]` | 控制箱数字量输入 |
| `digital_outputs` | `bool[]` | 控制箱数字量输出 |
| `analog_inputs` | `float32[]` | 控制箱模拟量输入 |
| `analog_outputs` | `float32[]` | 控制箱模拟量输出 |
| `tool_io_status` | `ToolIOStatus` | 工具端 IO 状态 |
| `is_connected` | `bool` | 与控制箱的连接状态 |

## 二、运动控制服务（srv）

### 4. MoveToPose — 运动到目标位姿

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `target_pose` | `geometry_msgs/Pose` | 目标 TCP 位姿 |
| `target_joints` | `float64[6]` | 目标关节角度（use_joints=true 时使用） |
| `use_joints` | `bool` | true=关节空间运动 / false=笛卡尔空间运动 |
| `velocity_factor` | `float32` | 速度倍率（0.0~1.0） |
| `acceleration_factor` | `float32` | 加速度倍率（0.0~1.0） |

**响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | `bool` | 运动是否成功 |
| `error_code` | `int32` | 错误码（0=成功） |
| `message` | `string` | 状态消息或错误信息 |

**使用示例：**

```python
# ROS 2 Python 客户端
from demo_interface.srv import MoveToPose
from geometry_msgs.msg import Pose

req = MoveToPose.Request()
req.use_joints = False
req.target_pose.position.x = 0.4
req.target_pose.position.y = 0.0
req.target_pose.position.z = 0.3
req.target_pose.orientation.w = 1.0
req.velocity_factor = 0.5
req.acceleration_factor = 0.5

future = move_to_pose_client.call_async(req)
```

### 5. Movel — 单轴直线运动

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `target_pose` | `geometry_msgs/Pose` | 目标位姿基线 |
| `velocity_factor` | `float32` | 速度倍率（0.0~1.0） |
| `acceleration_factor` | `float32` | 加速度倍率（0.0~1.0） |
| `move_axis` | `string` | 运动轴，仅支持 `"x"` / `"y"` / `"z"` |

**响应：** `success`, `error_code`, `message`

### 6. PlanTrajectory — 规划运动轨迹

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `target_pose` | `geometry_msgs/Pose` | 目标位姿 |
| `use_joints` | `bool` | true=关节空间规划 / false=笛卡尔空间规划 |

**响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | `bool` | 规划是否成功 |
| `trajectory` | `trajectory_msgs/JointTrajectory` | 规划生成的关节轨迹 |
| `planning_time` | `float32` | 规划耗时（秒） |
| `message` | `string` | 状态消息或错误信息 |

### 7. ExecuteTrajectory — 执行已规划轨迹

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `trajectory` | `trajectory_msgs/JointTrajectory` | 要执行的关节轨迹 |

**响应：** `success`, `error_code`, `message`

> 通常先调用 PlanTrajectory 获取轨迹，再调用 ExecuteTrajectory 执行。
> 也可以直接使用 MoveToPose（内部串行化规划和执行）。

### 8. SetRobotPose — 直接关节控制

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `target_pose` | `float64[6]` | 目标关节角/位姿 |
| `use_joints` | `bool` | true=关节空间 / false=笛卡尔空间 |
| `is_radian` | `bool` | 角度单位（true=弧度 / false=度），仅 use_joints=true 时有效 |
| `velocity` | `float32` | 运动速度 |

**响应：** `success`, `error_code`, `message`

## 三、配置与操作服务（srv）

### 9. GetCurrentState — 获取当前状态

**请求：** 无

**响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | `bool` | 请求是否成功 |
| `joint_position_rad` | `float64[]` | 当前 6 关节角度（弧度） |
| `cartesian_position` | `geometry_msgs/Pose` | 当前 TCP 位姿 |
| `velocity` | `float64[]` | 当前各关节速度 |
| `message` | `string` | 状态消息或错误信息 |

### 10. SetRobotEnable — 使能/去使能

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `enable` | `bool` | true=使能（上电） / false=去使能（下电） |

**响应：** `success`, `error_code`, `message`

### 11. SetSpeedFactor — 设置速度倍率

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `velocity_factor` | `float32` | 速度倍率（0.0~1.0） |

**响应：** `success`, `message`

### 12. SetRobotIO — 设置 IO 输出

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `io_type` | `string` | IO 类型（`"digital"` / `"analog"`） |
| `io_index` | `int32` | IO 通道索引（从 0 开始） |
| `value` | `float64` | 输出值（数字量 0/1，模拟量为电压/电流值） |

**响应：** `success`, `error_code`, `message`

### 13. ReadRobotIO — 读取 IO 状态

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `io_type` | `string` | IO 类型（`"digital"` / `"analog"`） |
| `io_index` | `int32` | IO 通道索引 |

**响应：** `success`, `value`（读取到的值）, `message`

### 14. ExecuteGraspPose — 执行抓取

**请求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `object_id` | `string` | 工件 ID |
| `use_visual_estimation` | `bool` | 是否使用视觉估计（false=使用预设参数） |

**响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | `bool` | 是否成功 |
| `message` | `string` | 状态消息或错误信息 |
| `final_position` | `geometry_msgs/Point` | 最终使用的抓取位置 |
| `final_orientation` | `geometry_msgs/Quaternion` | 最终使用的抓取姿态 |

---

## 接口依赖关系

```
消息依赖：
  RobotIOStatus ──→ ToolIOStatus

服务请求/响应中引用的外部消息：
  std_msgs/Header              — 时间戳和帧ID
  geometry_msgs/Pose           — 位置 + 四元数
  geometry_msgs/Point          — xyz 位置
  geometry_msgs/Vector3        — rpy 欧拉角
  geometry_msgs/Quaternion     — 四元数姿态
  trajectory_msgs/JointTrajectory — 关节轨迹
```

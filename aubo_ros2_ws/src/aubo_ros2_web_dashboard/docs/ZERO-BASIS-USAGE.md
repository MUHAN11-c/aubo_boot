# IVG Web Dashboard — 零基础使用文档

> **适用对象**: 零基础操作者 — 你只需要会打开浏览器和使用鼠标
> **目标**: 读完本文档后，能独立操作 IVG Web Dashboard 完成日常工作

---

## 第 1 章：系统概览

### 1.1 这是什么系统

IVG Web Dashboard 是一个**机械臂操作网页**。在浏览器里你可以：

- 看到机械臂的实时状态（在线/使能/运动/模式）
- 控制机械臂执行抓取
- 切换末端工具（夹爪）
- 看到相机实时画面
- 监控关节角度和末端位姿
- 控制咖啡拉花

### 1.2 打开系统

启动系统后（由管理员执行），在你的电脑浏览器输入：

```
http://<机械臂电脑的IP地址>:8090
```

例如：`http://169.254.10.11:8090` 或 `http://localhost:8090`（如果在同一台电脑上）喵~

## 第 2 章：页面功能介绍

打开后看到的是**门户首页**，顶部有导航栏，底部有状态栏喵~

### 2.1 导航栏

```
[灵视 IVG] [门户] [视觉抓取] [咖啡拉花] [监控面板] [日志] [设置]
```

点击即可切换页面，无需刷新浏览器喵~

### 2.2 底部状态栏

页面最下方固定显示 5 个状态指示灯：

| 指示灯 | 颜色含义 |
|--------|---------|
| **在线** | 绿色=已连接，灰色=离线 |
| **使能** | 绿色=电机已上电，灰色=未上电 |
| **运动** | 橙色=正在运动，灰色=静止 |
| **规划** | 绿色=空闲，橙色=规划中/执行中，红色=错误 |
| **模式** | 绿色=真机，橙色=仿真 |

> 如果所有灯都是灰色，说明机械臂未连接——检查机械臂是否开机喵~

## 第 3 章：各页面使用指南

### 3.1 视觉抓取页面（最重要！）

URL: `/vision`

**页面布局**：

```
┌─────────────┬──────────────┐
│ 模式切换     │  连接状态     │  ← 顶部工具栏
├─────────────┼──────────────┤
│ 3D 模型     │ 抓取控制      │
│ (左栏)      │ - 工件编号    │
│             │ - 单次/循环   │
│ 相机画面     │              │
│             │ 工具快换      │
│             │ - 当前工具    │
│             │ - 快换按钮    │
│             │              │
│             │ 服务日志      │
├─────────────┴──────────────┤
│ 末端位姿  │  关节角度       │  ← 底部数据区
└────────────┴───────────────┘
```

**工件模式操作流程**：
1. 确认顶部模式选择「工件（视觉估计）」
2. 在「目标工件编号」输入框输入工件编号
3. 点击「执行单次抓取」→ 机械臂自动完成一次抓取
4. 如需连续抓取，点击「启动循环」

**AI 大模型模式操作流程**：
1. 切换模式到「AI大模型抓取」
2. 点击「开始采集」→ 相机开始采集
3. 点击「循环抓取开」→ 开始连续抓取
4. 点击「循环抓取关」停止

**工具快换**：
1. 查看「当前: XXX」确认当前工具
2. 点击目标工具按钮（如「夹爪2 φ60」）
3. 等待机械臂自动完成切换

### 3.2 咖啡拉花页面

URL: `/latte`

**开关说明**：

| 开关 | 控制什么 |
|------|---------|
| 咖啡开关 (DO4) | 咖啡机出杯 |
| 打花开关 (DO2) | 拉花动作 |

**信号灯说明**：

| 灯 | 含义 |
|----|------|
| 咖啡反馈 (DI2) | 绿=咖啡机就绪 |
| 打花反馈 (DI3) | 绿=拉花完成 |
| 警告反馈 (DI4) | 黄=异常告警 |

### 3.3 监控面板

URL: `/monitor`

**功能**：
- 查看驱动模式（真机/仿真）
- 查看末端位姿（XYZ位置 + 四元数 + 欧拉角）
- 查看 6 个关节的角度
- 「记录当前快照」保存当前数据
- 「导出 JSON」批量导出记录

### 3.4 日志页面

URL: `/log`

**功能**：
- 实时查看系统日志（ROS 连接、话题订阅、服务调用）
- 搜索过滤：输入关键词筛选日志
- 暂停/恢复：点击「暂停」冻结日志
- 导出 TXT：保存日志到文件

### 3.5 设置页面

URL: `/settings`

**功能**：
- 查看网关状态（版本、端口）
- 修改 ROS 话题名/服务名
- 三个分类：公共参数 / 视觉抓取 / 咖啡拉花
- 「保存设置」写入配置（持久化）
- 「导出/导入 JSON」备份/恢复配置

## 第 4 章：日常操作速查

### 场景：执行一次完整抓取

```
① 打开 http://IP:8090/vision
② 确认底部状态栏「在线」为绿色
③ 确认模式为「工件（视觉估计）」
④ 输入工件编号 → 点击「执行单次抓取」
⑤ 观察底部关节角度变化 → 等待「服务日志」显示"成功"
```

### 场景：切换夹爪

```
① 打开 http://IP:8090/vision
② 在「末端夹爪快换」区域查看当前工具
③ 点击目标工具按钮
④ 等待日志显示"成功"
```

### 场景：查看机械臂当前状态

```
① 看底部状态栏 — 5 个指示灯一目了然
② 打开 http://IP:8090/monitor — 看详细数据
```

### 场景：修改相机话题名

```
① 打开 http://IP:8090/settings
② 在"公共参数"标签页找到「彩色相机图像」
③ 修改为新的相机话题名（如 /camera/color/image_raw）
④ 点击「保存设置」
```

## 第 5 章：常见问题

| 问题 | 解决 |
|------|------|
| 页面打不开 | 检查机械臂电脑是否开机，网络是否连通 |
| 状态灯全灰 | 机械臂未开机或 rosbridge 未启动 |
| 相机画面黑屏 | 相机未连接或话题名不匹配，检查设置页 |
| 点击抓取没反应 | 查看服务日志是否有报错 |
| 关节数据不更新 | 检查 rosbridge 连接状态 |
| 设置保存后不生效 | 点击保存后刷新页面 |
| 页面布局错乱 | 刷新浏览器（Ctrl+Shift+R 强制刷新） |

## 第 6 章：安全和注意事项

1. **执行抓取前确认机械臂工作范围内没有人**
2. **不要在抓取过程中切换页面** — 服务调用仍在后台进行
3. **仿真模式下 IO 控制无效** — 夹爪不会动作属于正常
4. **不要同时从多个浏览器标签页执行抓取** — 可能产生冲突
5. **修改设置后建议刷新页面** — 确保新配置生效

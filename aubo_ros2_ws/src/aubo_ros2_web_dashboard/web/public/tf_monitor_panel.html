与 URDF 的对应关系

TF 树里每一条边都是「父坐标系 → 子坐标系」的位姿；子帧名应对齐你在 URDF 里写的 <link name="…"> 或关节两端的 link。若某 link 在 RViz/网页里「飘走」，多半是 TF 里缺边、父名写错或与 robot_state_publisher 发布的静态树不一致。

本页仅订阅话题拼树，不加载 URDF；与「视觉抓取」面板共用同一套 WebSocket 连接方式。

机械臂自动咖啡拉花 应用扩展

本仓库当前以 IVG 抓取与视觉栈为主；「自动咖啡拉花」可作为独立应用场景： 由轨迹规划/示教、奶缸与杯位标定、以及上位调度（可选 Web）组成。若你已有对应 ROS 2 包或 launch， 可在此节增加按钮链到该前端或文档路径。

建议对接方式：在 demo_driver / MoveIt 上挂载专用节点，或通过本门户「ROS 控制台」观察话题与服务后再接业务 UI。

## 一、牛奶基础 (知识储备，非执行步骤)

| 成分 | 作用 | 热反应 |
|------|------|--------|
| 乳糖 (Lactose) | 甜味来源 | 140°F (60°C) 最佳释放 |
| 蛋白质 (Protein) | 泡沫结构 → 维持微泡形状 | 160°F (71°C) 变性→泡沫崩溃、发苦 |
| 脂肪 (Fat) | 口感/醇厚度 | 脂肪越多泡沫越绵密持久 |

**四个关键温度：**

| 温度 | 华氏 | 摄氏 | 状态 |
|------|------|------|------|
| 冷藏 | 40°F | 4°C | 糖/蛋白/脂肪各自分离，冷牛奶 |
| 微温 | 100°F | 38°C | 糖开始溶解，蛋白质展开，脂肪融化 |
| **最佳** | **140°F** | **60°C** | 糖全溶、蛋白拉伸到位 → 最佳甜度+口感 |
| 过烫 | 160°F | 71°C | 蛋白变性→苦味、泡沫消散 |

## 二、萃取咖啡液 (Espresso)

```
机械臂动作:
  1. moveToJoints → 取杯工位
  2. Cartesian Z下降 → 关IO(DO6)夹取空杯 → Z抬离
  3. moveToJoints → 咖啡机萃取口下方
  4. latte_node: /set_latte_do4 (true)  → DO4=ON → 咖啡机出液
  5. 等待萃取完成 (预设秒数 / DI2 反馈)
  6. latte_node: /set_latte_do4 (false) → DO4=OFF
  7. 得到 Espresso 基底
```

**参数:**
- 萃取时间: 预设 (一般 25-30 秒)
- DO4 控制: `/set_latte_do4` (std_srvs/SetBool)

## 三、蒸汽打发牛奶 (核心步骤)

### 3.1 牛奶准备
```
机械臂动作:
  1. 快换到 gripper1milkcup → 拾取奶缸
  2. 奶量规则:
     - 拿铁 (Latte):      25% 泡沫 → 倒冷奶至 75% 缸高
     - 卡布奇诺 (Cappuccino): 50% 泡沫 → 倒冷奶至 50% 缸高
  3. 移动到蒸汽棒下方工位
```

### 3.2 蒸汽打发操作
```
机械臂动作序列:
  1. 奶缸移至蒸汽棒正下方
  2. 蒸汽棒插入牛奶液面下 (深度: 刚没入液面)
  3. DO2=ON → 打开蒸汽
  4. ┌─ 第一阶段: 进气 (Aeration) ─┐
     │  奶缸保持 10-20° 倾斜          │
     │  蒸汽棒口刚好在液面下           │
     │  听到"撕纸声" = 正确            │
     │  哨声尖锐 = 插入太深→抬高奶缸    │
     │  持续至 ~100°F (38°C)           │
     └────────────────────────────┘
  5. ┌─ 第二阶段: 打绵 (Stretching) ─┐
     │  蒸汽棒插入更深 (口在液面下1cm)  │
     │  奶缸保持倾斜 → 牛奶旋转涡流     │
     │  持续加热至 140°F (60°C)         │
     │  奶缸外侧烫手无法触碰 = 到位     │
     └────────────────────────────┘
  6. DO2=OFF → 关闭蒸汽
  7. ┌─ 收尾 ─┐
     │  奶缸在桌面轻磕 → 震碎表面大气泡  │
     │  摇旋奶缸 → 混合泡沫与牛奶       │
     └────────────────────────────────┘
```

**ROS2 控制点:**
- DO2: `/set_latte_do2` → 蒸汽阀开关
- 温度监测: DI3 (可能需要外接温度传感器)
- 时间控制: 阶段1 约15-20秒，阶段2 约10-15秒

**故障判断:**

| 现象 | 原因 | 纠正 |
|------|------|------|
| 泡沫稀薄 / 很快消散 | 进气不足 (蒸汽棒太深) | 降低奶缸，让棒口更接近液面 |
| 泡沫粗厚 / 奶泡分离 | 进气过头 (蒸汽棒太浅) | 略抬高奶缸，蒸汽棒深入些 |

## 四、拉花注入 (Pouring) — 三个核心控制量

### 4.1 高度控制 (最关键)

| 高度 | 效果 | 何时用 |
|------|------|--------|
| **3 英寸** (~7.5cm) 高于液面 | 奶泡穿透 Crema 沉入杯底，表面保持深色 | 填充阶段 |
| **1 英寸** (~2.5cm) 高于液面 | 部分泡沫浮出，过渡阶段 | 准备出图 |
| **触碰杯缘** (0cm) | 泡沫停留在表面形成白色图案 | 出图阶段 |

```
注入高度控制 → 对应机械臂 Cartesian Z 轴高度:

  Z_surface + 7.5cm  ← 填充 (3 英寸)
  Z_surface + 2.5cm  ← 过渡 (1 英寸)
  Z_surface + 0cm     ← 出图 (杯缘接触)
```

### 4.2 流量控制

```
规则: 流量应从低到高逐渐增加

原因: 杯中液面上升 → 容积增大 → 需更多流量维持图案推力

机械臂映射:
  - 流量 ↑ = 奶缸倾角 ↑ (倾斜越大，出奶越多)
  - 或通过设定奶缸 Z 高度控制 (重力出奶)
```

### 4.3 位置控制

```
规则: 注入点决定图案形状

  杯心正中央      → 圆形/心形 (对称图案)
  杯心偏上方      → 图案向近端聚集
  杯心偏前/偏后   → 图案偏移
```

## 五、三种基础拉花图案

### 5.1 实心心形 (Solid Heart) — 入门必学

```
步骤:
  ┌───────────────────────────────────────────┐
  │ 1. 3" 高度 → 注入至杯子 70% 满            │
  │    (保持液面深色，不出现白色)              │
  │                                           │
  │ 2. 降至 1" 高度 → 杯心位置开始形成白色圆点  │
  │    (Monk's Head "僧侣头")                 │
  │                                           │
  │ 3. 液面接近满杯时:                         │
  │    抬高奶缸至 3"                           │
  │    奶流从圆点中心穿过 → 拉出心形尾巴        │
  │    (动作: 从近端向远端直线划过)             │
  │                                           │
  │ 4. 到达杯底时立即停止注入 → 完成           │
  └───────────────────────────────────────────┘

Cartesian 路径:
  waypoint[0]: (X_center, Y_near, Z_surface+7.5)   ← 填充 70%
  waypoint[1]: (X_center, Y_center, Z_surface+2.5)  ← 形成白圆
  waypoint[2]: (X_center, Y_far, Z_surface+7.5)     ← 拉尾穿过
```

### 5.2 波动心形 (Rippled Heart)

```
步骤:
  ┌───────────────────────────────────────────┐
  │ 1. 与实心心形同样开始                      │
  │                                           │
  │ 2. 出图时: 奶缸在杯心位置左右摆动           │
  │    (手掌前后推拉 → 频率均匀)                │
  │    → 牛奶在杯中形成楼梯状波纹              │
  │                                           │
  │ 3. 保持高流量 → 不失去推力                 │
  │    (因为波纹扩散面积大，力被分散)           │
  │                                           │
  │ 4. 摆动至满杯 → 抬升至 3" 拉尾穿过          │
  └───────────────────────────────────────────┘

Cartesian 路径:
  在 Y 轴 (前后) 上叠加正弦摆动:
    Y(t) = Y_center + A * sin(ω*t)
    A (振幅) ≈ 0.5~1.0 cm
    ω (频率) ≈ 2-3 Hz
```

### 5.3 郁金香 (Tulip) — 层叠心形

```
步骤:
  ┌───────────────────────────────────────────┐
  │ 1. 3" 填充至杯面暗色                       │
  │                                           │
  │ 2. 第一层: 杯心 → 形成一个小白心            │
  │    当心的顶部开始出现 → 停止注入            │
  │                                           │
  │ 3. 第二层: 在第一层心的正上方 → 再注入       │
  │    形成第二个心，被第一个心包裹              │
  │                                           │
  │ 4. 第三层: 继续在上方叠加                   │
  │    (杯有空间就继续，一般 3-4 层)            │
  │                                           │
  │ 5. 最后一层完成后 → 抬升 3" 拉尾穿过所有层   │
  └───────────────────────────────────────────┘

Cartesian 路径:
  waypoint[0]: (X_center, Y_1, Z+7.5) → 填充
  waypoint[1]: (X_center, Y_1, Z+2.5) → 倒第1层 → 暂停注入
  waypoint[2]: (X_center, Y_2, Z+2.5) → 倒第2层 → 暂停注入
  waypoint[3]: (X_center, Y_3, Z+2.5) → 倒第3层 → 暂停注入
  waypoint[4]: (X_center, Y_end, Z+7.5) → 拉尾穿过
```

### 5.4 叶子 (Rosetta) — 进阶

```
步骤:
  ┌───────────────────────────────────────────┐
  │ 1. 3" 填充至杯面暗色                       │
  │                                           │
  │ 2. 降至杯心 → 开始左右摆动 + 慢慢向远端后退  │
  │    流量保持均匀，摆动频率不变               │
  │    → 形成叶子纹路                          │
  │                                           │
  │ 3. 后退至杯顶 → 停下摆动                    │
  │    保持注入形成一个圆点 (叶尾)              │
  │                                           │
  │ 4. 抬升 → 直线从叶中穿过 → 完成             │
  └───────────────────────────────────────────┘

Cartesian 路径:
  while Y from Y_near to Y_far:
    Y -= ΔY_step
    X = X_center + A * sin(ω * Y)
    逐步后退 + 持续摆动
```

## 六、两种基本形状单元

所有拉花图案都由两个基本形状组合而成:

| 形状 | 形成方式 | 用于 |
|------|---------|------|
| **心形 (Heart)** | 保持注入点不动 (或微前推) | 心形、郁金香 |
| **圆形 (Circle/Blob)** | 向后拉注入点 | 叶子纹路、Rosetta 基底 |

## 七、完整 ROS2 执行流程

```
  启动:
    latte_node       ← IO 控制 (DO2/DO4 + DI 反馈)
    gripper_swap_worker ← 工具快换
    move_group       ← MoveIt2 运动规划

  ════════════════════════════════════════════
  阶段 1: 取杯 + 萃取
  ════════════════════════════════════════════
  1  changeToTool("gripper1coffeecup")
  2  moveToJoints → 取杯工位
  3  Cartesian Z↓ → DO6=ON(夹取) → Z↑
  4  moveToJoints → 萃取工位
  5  DO4=ON → 等待萃取
  6  DO4=OFF

  ════════════════════════════════════════════
  阶段 2: 打发牛奶
  ════════════════════════════════════════════
  7  moveToJoints → 奶缸 dock
  8  changeToTool("gripper1milkcup")
  9  moveToJoints → 蒸汽棒工位
  10 DO2=ON
  11 Cartesian: 空气注入阶段 (棒口近液面, ~15s)
  12 Cartesian: 打绵阶段 (棒口深入, 加热至60°C, ~12s)
  13 DO2=OFF
  14 轻磕旋摇 (Cartesian 小幅上下 + 旋转)

  ════════════════════════════════════════════
  阶段 3: 拉花执行
  ════════════════════════════════════════════
  15 moveToJoints → 拉花起始位姿 (杯口上方3")
  16 Cartesian: 填充 (Z+7.5cm, ~5s)
  17 Cartesian: 出图轨迹 (心形/郁金香/叶子)
  18 moveToJoints → camera_pose (安全位)
  19 放置成品
```

## 八、机械臂参数映射

| 拉花参数 | 机械臂轴 | 说明 |
|---------|---------|------|
| 注入高度 | TCP Z (相对杯面) | 3英寸=7.5cm / 1英寸=2.5cm / 0=触杯 |
| 注入位置 | TCP X, Y (相对杯心) | 位置决定图案走向 |
| 流量 (出奶量) | 奶缸倾角 (TCP roll/pitch) | 倾角越大→流量越大 |
| 摆动 | TCP Y (前后往复) | 正弦波 A≈0.5~1cm, f≈2~3Hz |
| 拉尾 | 从近端到远端直线划过 | Cartesian line |
| 蒸汽棒入液深度 | TCP Z (相对液面) | 刚没入≈0mm / 深入≈10mm |

# 心形拉花轨迹数据集

> 从 `ridxm/latte-pour-demos` (HuggingFace) 的 40 段 RM65 双机械臂示教数据中筛选、优化、参数化生成的心形拉花轨迹喵~

## 数据来源

40 段原始录制轨迹分类结果（right arm, 拉花执行手）:

| 图案 | 数量 | 占比 |
|------|------|------|
| 心形 (Heart) | 15 | 38% |
| 心形变体 (Heart-like) | 8 | 20% |
| 心形/郁金香 | 6 | 15% |
| 简单划线 | 5 | 12% |
| 树叶 (Rosetta) | 3 | 8% |
| 轻微摆动 | 3 | 8% |

**心形系列合计 29/40 = 73%**，本数据集以心形为主喵~

## 心形轨迹结构

基于 `latte_art_robot_research` 参考项目 + Sunergos/latteartguide 多源教程，心形拉花的关键物理阶段:

```
┌──────────┐   ┌──────────────┐   ┌──────────┐   ┌────────────┐
│ 融合注入   │ → │ 成形微摆+前推  │ → │ 竖直抬起   │ → │ 划穿收尾     │
│ Z高位     │   │ Z低位(液面)   │   │ Z快速上升  │   │ Z高位拉线   │
│ ~25%时间  │   │ ~45%时间     │   │ ~10%时间  │   │ ~20%时间   │
└──────────┘   └──────────────┘   └──────────┘   └────────────┘
   高位           杯前1/3处          产生"吸力"        穿过白色
   细流注入        微摆+前推         圆形→心形         图案中心
```

### 录制数据 vs 参数化轨迹

| 维度 | 录制数据 (raw) | 参数化轨迹 (parametric_full) |
|------|---------------|---------------------------|
| 轨迹来源 | 人类示教录制 | 数学公式生成 |
| X 振幅 | 15-21cm (含接近运动) | 4mm (仅液面微摆) |
| 路径长度 | 1.3-1.9m | 0.9m |
| 可调参数 | 无 (固定) | cup_x/y/z, radius, sway_amp, push_dist, pitch |
| 噪声 | 有人类手部自然抖动 | SG平滑, 无噪声 |
| 适用场景 | 行为克隆回放 | 参数化轨迹生成 |

**使用建议**:
- **真机执行**: 用 `heart_optimized_ep32.npz` 或 `heart_ensemble_top5.npz`（完整接近/退出路径）
- **仿真调试**: 用 `heart_parametric_full.npz`（干净、可解释、可调参）
- **研究分析**: 对比 raw vs parametric 理解人类示教中的"额外运动"

## 坐标系

所有轨迹在 **RM65 base_link** 坐标系中录制:
- X: 前方 (机器人前方)
- Y: 左方 (机器人左侧)
- Z: 上方

液面位置约 Z=22cm, 杯中心约 (-0.28, -0.03, 0.22) 米喵~

通过 `latte_imitation.retarget_trajectory()` 的 SE(3) 变换可适配到 AUBO E5 工作空间喵~

# 机械臂拉花：末端旋转与运动逻辑分析

## 1. 拉花运动学本质

拉花 = **拉花缸在咖啡液面上方的 2.5D 轨迹运动**

```
自由度需求:
├── 平移 X, Y   ← 图案轨迹 (2D视频可提取)
├── 平移 Z       ← 壶嘴距液面高度 (~1-3cm, 基本恒定)
├── 旋转 Pitch   ← 倾倒角度 (控制流速, 最关键)
├── 旋转 Yaw     ← 壶嘴指向 (跟轨迹方向相关)
└── 旋转 Roll    ← 侧倾 (对称图案可忽略)
```

## 2. 末端旋转怎么来

视频只给 2D 像素轨迹，旋转需要额外推导。分两种情况：

### 2.1 使用 YOLO OBB 旋转框

OBB 本身就输出旋转角度 `θ` 和 4 个角点:

```
OBB 输出:
├── θ (旋转角)      → 直接映射为末端 Yaw
├── aspect_ratio    → 间接估计 Pitch (缸越平 aspect_ratio 越小)
└── center (cx,cy)  → 壶嘴/缸体中心 2D 位置
```

**OBB 的优势**: 旋转框天然适合倾斜的拉花缸，比水平框精确得多。

### 2.2 Pitch 角估计

当视频是侧拍视角时:
```
缸体接近垂直 → 图像中缸体短 → 小 Aspect Ratio
缸体接近水平 (倾倒中) → 图像中缸体长 → 大 Aspect Ratio
```

对于俯拍视角，则只能看到 XY 平面运动，Pitch 需要:
- 预设值 (如固定 35° 倾倒角)
- 或通过缸体顶部/底部相对位置推断

### 2.3 旋转执行方式

Aubo 臂用 `/move_to_pose` 时直接给 `geometry_msgs/Pose`:

```python
Pose position:  x, y, z       # 壶嘴位置
Pose orientation: qx,qy,qz,qw # 缸体姿态 (四元数)
```

或通过 `/execute_trajectory` 发送 `JointTrajectory`（MoveIt自动IK）。

## 3. 拉花完整运动逻辑

### 3.1 拉花心形 (Heart) 运动分解

```
Phase 0: 起始
  位置: 杯子中心上方 3cm
  姿态: Pitch≈60° (几乎水平,高速注入奶泡)
  
Phase 1: 奶泡注入 (高倾倒角, 大流量)
  位置: 杯子中心不动
  姿态: Pitch 60°→45°, 奶泡沉入咖啡形成白色基底
  时长: ~3秒

Phase 2: 心形绘制 (低倾倒角, 小流量)
  位置: 从中点向前拉, 画心形弧线
  姿态: Pitch≈30°, Yaw 跟随运动方向变化
  轨迹: 弧形 "?" 形状
  时长: ~2秒

Phase 3: 收尾 (最小倾倒角, 微量)
  位置: 心形中间直线穿过
  姿态: Pitch≈15°, 壶嘴几乎垂直
  时长: ~1秒
```

### 3.2 状态机

```
[IDLE] → 移动到起始位姿
    ↓
[FILL]  → 大流量注入奶泡 (Pitch 45-60°)
    ↓  (时间触发: ~3s)
[DRAW]  → 轨迹绘制 (Pitch 20-30°, 跟随轨迹)
    ↓  (轨迹完成)
[FINISH] → 提壶收尾 (Pitch 10-15°, Z上升)
    ↓
[IDLE]  → 回到安全位姿
```

### 3.3 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Z_work | 杯子高度 + 2cm | 壶嘴距液面 |
| pitch_pour | 30-45° | 倾倒角 |
| v_draw | 1-3 cm/s | 绘制速度 |
| v_travel | 5-10 cm/s | 空移速度 |
| trajectory_hz | 10-20 Hz | 轨迹发送频率 |

## 4. 视频→机器人 映射

### 4.1 坐标变换链

```
pixel (u,v) → 相机坐标系 (Xc,Yc,Zc) → 机器人基座 (Xr,Yr,Zr)
    ↑                    ↑                      ↑
  图像提取           相机内参K              手眼标定 T
```

### 4.2 简化方案 (桌面平面假设)

如果拉花在桌面平面上进行（液面高度已知）:

```
1. H = 单应矩阵 (像素平面 → 桌面平面)
   通过4个标定点 (杯子4角) 计算
2. pixel (u,v) * H → 桌面坐标 (X,Y)
3. Z = 桌面高度 + 液面高度 + 壶嘴间隙
4. Pitch = 预设轨迹或OBB估算
5. Yaw = OBB角度 或 速度方向 + 偏移
```

## 5. 第一阶段实现：OBB 检测 + 轨迹提取 + 旋转

```
视频帧 → YOLO OBB → 拉花缸旋转框
    ├── center (cx,cy) → 轨迹点
    ├── angle θ → 末端 Yaw
    ├── aspect_ratio → 末端 Pitch (近似)
    └── 4角点 → 壶嘴位置 (取最低点/最前端)

轨迹后处理:
    EMA平滑 → 降采样10Hz → 发送到机器人
```

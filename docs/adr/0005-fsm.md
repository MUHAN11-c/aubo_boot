# ADR 0005：supervisor 保留纯核 FSM，不迁移 BehaviorTree

## 决策

`peach_supervisor` 继续使用纯核 `harvest_fsm` + reducer；不迁移 BehaviorTree.CPP/py_trees。

## 理由

- 当前 FSM 是已实测的确定性采摘逻辑，迁移会改变行为与失败边界。
- Nav2 的 BT 面向导航行为编排，不是“所有任务必须 BT”。
- 纯核 FSM 易测、无 ROS 依赖，符合端口/适配器边界。

## 后果

- supervisor 采用 Nav2 式 lifecycle/action/bond，但保留 FSM。
- 若未来需要可视化行为编排，另立专项 ADR。

# latte-pour-demos 数据集分析

> 理解数据集中"靠近→倒咖啡→离开"的完整轨迹

## 数据集概览

| 属性 | 值 |
|------|-----|
| **格式** | LeRobot v3.0 |
| **机器人** | Realman RM65 双臂 (14-DOF = 7×2) |
| **任务** | "Pour the coffee into the cup" |
| **总集数** | 40 episodes |
| **每集帧数** | 400 帧 |
| **帧率** | 20 FPS |
| **每集时长** | 20.0 秒 |
| **总帧数** | 16,000 帧 |
| **状态维度** | 14 (关节角度, rad) |
| **动作维度** | 14 |
| **摄像头** | 3 个: top_camera, left_wrist, right_wrist (480×640) |

## 文件说明

| 文件 | 功能 |
|------|------|
| `analyze_dataset.py` | 关节轨迹分析、摆动检测(FFT)、平滑度评估、教程参数对比 |
| `segment_trajectory.py` | **三阶段分割** (靠近/倒奶/离开)、倒奶子阶段检测、纯倒奶段提取 |
| `visualize_trajectory.py` | 可视化 (单集概览/批量对比/理论与数据对比/阶段分割图) |
| `pouring_trajectories.npz` | 提取的 40 段纯倒奶关节轨迹 (已去除靠近和离开) |

## 使用方法

```bash
# 三阶段分割 (核心)
python analysis/segment_trajectory.py --episode 20          # 单集分割
python analysis/segment_trajectory.py --plot                # 全部分割+绘图
python analysis/segment_trajectory.py --extract-all         # 提取纯倒奶段

# 关节运动分析
python analysis/analyze_dataset.py --episode 20
python analysis/analyze_dataset.py --compare-tutorial

# 可视化
python analysis/visualize_trajectory.py                     # 全部默认图表
```

## 核心发现: 三阶段时间分布

```
20秒完整轨迹 = 靠近(7.8s) + 倒奶(2.3s) + 离开(9.9s)

  ┌──────────────┬─────┬──────────────────────────┐
  │  靠近阶段     │ 倒奶 │  离开阶段                  │
  │  7.8±5.7s    │2.3s │  9.9±5.7s                 │
  │  (39%)       │(12%)│  (50%)                     │
  └──────────────┴─────┴──────────────────────────┘
```

### 关键洞察

1. **真正的倒奶只有 ~2.3 秒**（占全程仅 12%）
   - 远短于人类拉花的 3-10 秒
   - 确认这是"倒咖啡"而非"拉花图案"

2. **靠近和离开阶段差异极大** (标准差 ~5.7s)
   - 有些 episode 从杯子旁边开始 (接近 0.2s)
   - 有些从远处开始 (接近 18s)
   - 解释了为什么之前的简单分析得出"左臂活动量大"的结论——离开阶段的左臂大范围移动

3. **倒奶段内又分为三个子阶段**:
   ```
   倒奶 2.3s = 融合(~35%) + 成形(~40%) + 收尾(~25%)
   ```

4. **成形阶段存在周期性运动**: 检测到 339 次 >0.5Hz 的摆动
   - 最高频率 9.29Hz——高于人类拉花(3-6Hz)
   - 但这些高频成分更可能是机械振动/传感器噪声
   - 主要摆动集中在左臂(持杯臂)关节, 右臂(倒奶臂)相对稳定

5. **右/左臂活动比**: 在纯倒奶阶段约为 0.5
   - 左臂(持杯)活动量是右臂(倒奶)的 ~2 倍
   - 与教程中"杯子持续旋转/倾斜回正"一致

## 与拉花教程参数的对比

| 参数 | 人类教程 | 数据集(纯倒奶段) | 分析 |
|------|---------|----------------|------|
| 倒奶时长 | 3-10s | **2.3s** | 快,简单倒咖啡 |
| 摆动频率(成形) | 3-6 Hz | 检测到 2.5-9.3Hz | 高频可能为噪声 |
| 融合占比 | ~20-30% | ~35% | 接近 |
| 成形占比 | ~50-60% | ~40% | 偏低 |
| 收尾占比 | ~10-20% | ~25% | 接近 |
| 杯子倾斜(左臂) | 30-45° | 左臂活动量大(间接) | 需FK精确计算 |

## 对机械臂拉花的启示

### 该数据集适合什么
- **倒咖啡基础动作**的学习 (靠近→倒奶→离开的基本节奏)
- **双臂协调**参考 (倒奶臂稳定 + 持杯臂旋转)
- 任务结构的理解 (靠近→执行→离开的范式)

### 该数据集不适合什么
- **拉花图案轨迹**的学习 (没有 Rosetta、郁金香等图案动作)
- 高频摆动 (3-6Hz) 的生成

### 建议
1. 用此数据集训练"倒咖啡"的基本动作模型
2. 在倒奶段上**叠加参数化拉花轨迹** (来自 `latte_art_trajectory.py`)
3. **收集专门的拉花示教数据** (Rosetta/心形/郁金香), 每集约 5-8 秒纯动作
4. 将 20s 完整轨迹视为 task-level 框架, 2.3s 倒奶段可替换为拉花动作

# 02 模块与责任边界

模块是能力/责任边界，不等于立即新增12个ROS包、12个进程或12套管理器。可以保留成熟实现并按边界重构适配，模块间走稳定的任务、状态、事件和结果。

## M01 果园与作业资源

负责：维护果园、行、树/作业点、通行区、禁行区和补给站的长期资产。

输入：人工配置、地图、巡检结果、作业资源更新。

输出：可引用的作业区、作业点、路线约束、卸载/补能站信息。

边界：不发送底盘或机械臂指令；长期资产与实时避障场景分开。

关联页面：果园与路线 / 配置维护。

## M02 任务与全局调度

负责：唯一管理一次果园作业，分解任务、选择下一作业点、协调采摘/卸载/补能/恢复。

输入：作业目标、果园资源、各模块进度、容量/电量/健康与人工意图。

输出：导航任务、作业点任务、资源处置任务、整任务进度与任务账本。

边界：不做路径规划、目标拟合或刀具控制；不得把导航成功直接结算成作业点完成。

关联页面：任务总览 / 现场作业 / 故障恢复。

## M03 定位与自主导航

负责：负责机器人全局定位、路线执行、局部避障与导航任务结果。

输入：地图与通行规则、定位传感、导航目的地、平台状态。

输出：位置/定位健康、导航进度、到达/失败/取消结果、移动状态。

边界：不选果、不剪切；采用Nav2等成熟能力，传感器组合与规划器后续再选。

关联页面：果园与路线 / 现场作业 / 故障恢复。

## M04 作业点定位与移动—采摘交接

负责：将导航目的地转换为可开始采摘的稳定工作状态，并管理重新定位与离场许可。

输入：导航结果、底盘稳定状态、作业区约束、机械臂状态、局部场景可用性。

输出：作业点就绪/拒绝、观察范围、重新定位请求、允许移动的交接结果。

边界：导航到达≠稳定就绪；移动导致原局部场景失效；首版采用底盘移动与采摘互斥。

关联页面：现场作业 / 果园与路线。

## M05 场景感知与目标发现

负责：产出果实/外袋、枝叶/主枝、障碍与目标身份等可观察事实。

输入：相机/空间传感、标定、机器人位姿与当前工作区。

输出：目标集合、身份与观察质量、环境障碍、需要补充观察的事实。

边界：不授权工具、不决定下一颗；检测事实与执行可行性分开。

关联页面：感知与目标 / 现场作业。

## M06 局部建模与操作条件评估

负责：为当前目标建立局部几何、接近/剪切参考、障碍约束与可操作条件。

输入：绑定目标、多视观察、工具/标定档案、局部机器人姿态与场景。

输出：目标模型、候选操作方案、分能力评估、拒绝或重观察原因。

边界：区分可见几何与工艺推断；只生产模型/条件，不发运动，不越过执行侧复核。

关联页面：感知与目标 / 现场作业 / 配置维护。

## M07 采摘策略与单果调度

负责：在当前作业点管理候选优先级、补观察、单果周期与补采清单。

输入：目标事实、模型评估、臂/工具可用性、作业点预算、全局任务约束。

输出：观察/采摘周期请求、单果终局、作业点汇总、跳过与补采原因。

边界：不承担全园导航调度；全局任务与单果结果分别记账；任何重试均有边界。

关联页面：现场作业 / 感知与目标 / 记录报告。

## M08 机械臂规划与运动执行

负责：负责观察、接近、预抓取、接触、撤离、收集位等运动与阶段反馈。

输入：当前任务、有效目标模型、工具与场景约束、执行权限。

输出：规划结果、实际阶段、到位证据、失败/取消结果、恢复状态。

边界：统一最后运动输出检查；规划与执行分开；失败不执行残缺方案。

关联页面：机械臂与工具 / 现场作业 / 故障恢复。

## M09 末端工具与采摘验证

负责：负责工具动作、抓持/剪切/承接的设备状态及独立结果证据。

输入：有效阶段请求、工具档案、设备反馈、验证传感器。

输出：指令受理、工具反馈、物理剪断/承接证据、未知状态和工具故障。

边界：工具动作与臂运动同级危险；ACK、工具到位、物理剪断不是同一事实；不暴露网页直接SetIO。

关联页面：机械臂与工具 / 收集物流 / 故障恢复。

## M10 收集物流与资源管理

负责：维护果实去向、容器、承接/释放、卸载与补能需求，避免任务因资源不足失控。

输入：单果结果、容器/负载反馈、电量、站点与服务可用性。

输出：收集确认、容器状态、卸载/补能请求、资源就绪结果。

边界：资源模块请求处置，由M02编排；不私自抢导航、不把切断数当入箱数。

关联页面：收集物流 / 任务总览 / 现场作业。

## M11 运行权限、健康与恢复

负责：统一作业模式、命令权限、底盘—臂互斥、节点/传感健康和分级恢复。

输入：人工授权、硬件安全状态、故障与心跳、任务/阶段和资源状态。

输出：可运行条件、拒因、撤权/应用停止请求、人工处理与恢复条件。

边界：硬件急停独立于ROS；实际强制位于各执行通道末端；不自动恢复旧危险轨迹。

关联页面：故障恢复 / 现场作业 / 配置维护。

## M12 数据闭环与Web工作台

负责：汇聚全项目任务、地图、目标、执行、物流和异常，支持可追溯记录与复盘。

输入：各模块状态/事件/结果、会话与配置、人工注记。

输出：作业页面、模块健康、任务/单果/物流报告、回放与证据索引。

边界：展示不持有控制状态机；操作经业务入口；视图选中不改变执行绑定；离线数据与实机状态分开。

关联页面：全部页面。

## 跨模块关系与契约

- 任务调度 → 导航：目的地、约束和取消意图；导航 → 调度：结果与定位健康。
- 导航 → 作业点交接：到达与移动状态；交接 → 调度/采摘：工作点就绪或重新定位原因。
- 感知/建模 → 单果策略：目标事实、操作条件与有效范围；策略 → 臂/工具：明确当前目标的能力任务。
- 臂/工具 → 单果策略：阶段、结果和恢复要求；单果策略 → 全局任务：作业点进度与终局。
- 收集资源 → 全局任务：容量/补能/卸载需求；任务调度 → 导航/站点：资源处置任务。
- 健康权限横切全部能力；实际指令强制在底盘和臂/工具各自最后执行通道，保持统一策略。
- Web/记录订阅各层状态；人工意图经相应业务入口，不能绕开调度/执行权威。

任务契约需表达目标、作用域、生命周期、取消与终局；事实流需表达来源、时间与适用上下文；结果需表达成功/失败/未知、实际达到阶段、证据和恢复要求。本阶段不展开IDL字段或具体API路径。

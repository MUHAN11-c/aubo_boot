# 04 Web产品结构与页面设计

## 产品信息架构

默认进入任务总览。主导航按完整机器人作业组织，研发实验台作为辅助入口，不让六步臂实验定义整个产品。首屏体现任务、工作区、机器人、当前模式、主要阶段与阻挡；在实时产品中，未知模式/来源不能默认当真机。

全局任务上下文贯穿页面；果园与路线围绕作业区/工作点；现场作业围绕当前工作点/目标；执行、物流与报告各自保留证据和终局。查看选中与执行绑定分开。数据图层按长期地图、导航障碍、局部模型和执行轨迹分层，不用隐藏图层删除控制约束。

建议桌面布局：左侧模块导航与任务层级；中央地图/场景/流程；右侧当前对象、下一步条件与人工处理；底部事件/进度/证据。小屏重排为单栏，二维地图与表格在自己的容器内操作。工程详情可展开，不作为默认首屏。地图仅在真实或明确仿真数据接入时显示；本设计原型用作业点拓扑示意，不冒充真实果园地理图。

## 页面清单

### P01 任务总览

回答：这项果园作业做到哪里，还剩什么，为什么停下？

内容：作业目标/作业区/阶段；行与作业点队列；导航/采摘/物流综合进度；资源与健康摘要；发现/尝试/确认采摘/入箱/补采分别统计。

操作类别：创建/审核任务；开始/暂停/取消任务；查看未完成清单。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M01 / M02 / M10 / M11 / M12。

### P02 果园与路线

回答：去哪里、怎么去、哪些区域不能进入？

内容：真实地图与定位（接入后）；行/作业点/站点及路线；通行/禁行/障碍；定位与导航状态；到位、稳定与离场的区别。

操作类别：选择作业区域；调整作业点顺序；查看或申请重新定位。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M01 / M03 / M04 / M11。

### P03 现场作业

回答：当前工作点与目标正在做什么，下一步是什么？

内容：任务—工作点—目标上下文；图像/局部模型与当前目标；全流程阶段与下一步条件；工具/承接/撤离证据；异常与独立取消位置。

操作类别：在可用权限内启动作业点；申请补观察/跳过；人工接管与恢复确认。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M02 / M04 / M05 / M06 / M07 / M08 / M09 / M11。

### P04 感知与目标

回答：看到了什么，哪些可采，哪些还需要观察？

内容：稳定目标集合与候选；实测/融合/推断分层；目标质量与可操作条件；覆盖与未观察区域；拒绝/补采原因。

操作类别：选择查看目标；查看来源与条件；申请重新观察。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M05 / M06 / M07。

### P05 机械臂与工具

回答：规划、执行和采摘结果各到哪一步？

内容：机器人与工具档案；计划/实走与动作阶段；预抓取/套入/剪切/撤离；工具状态与验证证据；运行与维护模式区别。

操作类别：只规划预览；按业务权限执行单步；取消执行/请求维护。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M08 / M09 / M11。

### P06 收集物流

回答：果实去了哪里，容器与电量能否支撑继续作业？

内容：承接—带离—释放—入箱；容器/负载与待卸载；电量/补能/站点；卸载与补能任务进度；人工换箱/装置未接说明。

操作类别：请求卸载/补能；确认人工换箱；查看物流差异。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M02 / M09 / M10 / M11。

### P07 故障恢复

回答：问题在哪个模块，影响哪些任务，需要谁处理？

内容：故障按任务/模块/原因聚合；导航/作业点/采摘/工具/物流影响；建议处置与允许恢复条件；应用停止与硬件安全状态；人工操作与恢复审计。

操作类别：取消相关任务；确认现场处理；在条件满足后重新下发。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M02 / M03 / M07 / M08 / M09 / M10 / M11。

### P08 记录报告

回答：能否还原这次作业，失败与效率主要受什么影响？

内容：任务与工作点账本；单果/承接/物流结果；会话回放与事件时间轴；工况/配置对照；效率、损伤、遗漏与人工介入。

操作类别：查看/导出任务报告；回放/比较作业；补充不改变事实的注记。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M02 / M07 / M10 / M12。

### P09 配置维护

回答：哪套机器人、地图、工具与工艺正在服务这项任务？

内容：机器人与地图版本；相机/工具/标定档案；工艺策略与任务默认；用户/操作模式/权限；设备维护与部署事实。

操作类别：审核配置版本；维护模式下改允许项；交班/退出检查。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：M01 / M03 / M08 / M09 / M11 / M12。

### P10 研发实验台

回答：哪个模块或交接边界尚未通过验收？

内容：导航/采摘/工具/物流独立验证；完整闭环模拟/回放/真机分类；六步采摘作为局部实验流程；跨模块交接与故障场景；当前实现进度与证据缺口。

操作类别：选择试验场景；查看验收结果；导出复现实验包。操作出现不代表当下拥有权限；真实产品必须业务回读和执行侧校验。

服务模块：全部模块。

## 关键页面联动

任务→行/工作点→目标→执行结果→收集结果→报告可逐层钻取。导航受阻从路线页跳到同任务故障；模型不满足从现场页跳到目标条件；工具结果未知跳到人工恢复；容器不足跳到物流处置；查看报告可以回到同上下文的录像/事件。

## 界面原型的范围

原型用于评审模块位置、任务层级、闭环和异常分支，所有情境都明确标“设计情境演示”。只改变视图，不发送ROS命令。既有真实相机样本仅作模块背景参考，不成为全园实时状态。原型不承诺完整3D数字孪生、真实地图、实时数据、已接传感或机器人业务已完成。

## 功能规划原则

任务管理、路线与工作交接、目标与模型、机械臂/工具、物流资源、故障恢复、账本/报告、配置维护必须在完整框架中出现。高级自动地图更新、多机派单、自动果实质量分级、输送/自动换箱、持续视觉伺服等按产品需要后续实现，不让局部算法细节阻塞整体框架。

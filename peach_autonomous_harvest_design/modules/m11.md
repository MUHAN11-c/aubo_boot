# M11 运行权限、健康与恢复

负责：统一作业模式、命令权限、底盘—臂互斥、节点/传感健康和分级恢复。

输入：人工授权、硬件安全状态、故障与心跳、任务/阶段和资源状态。

输出：可运行条件、拒因、撤权/应用停止请求、人工处理与恢复条件。

边界：硬件急停独立于ROS；实际强制位于各执行通道末端；不自动恢复旧危险轨迹。

关联页面：故障恢复 / 现场作业 / 配置维护。


## v1资料的复用与验证方向

保留运动与工具统一授权、默认关、健康/心跳和人工恢复边界；需验证失联、撤权对在途动作的实际效果。硬件急停独立，旧配置开关或网页菜单不产生授权。详见[docs合并与基线](../10_docs_merge_and_baseline.md)。

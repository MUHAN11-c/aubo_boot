# Web 可视化与布局验收 · 2026-10-14

本轮修改现有 peach_web 与 peach_observability。白色主题；相机、三维与分析集中展示；保留全部既有操作。

## 几何与路径证据

- 三维标注感知/融合袋底、袋口、中心；P 预抓取、E 袋外入口、C 剪切参考；袋轴与参考路径；实际工具 TF 与历史 TCP 轨迹。密集标签避让并使用引线连接真实点，历史轨迹末端不冒充实时工具 TF。
- 计算后撤、入口至剪切距离、轴向投影、横向偏差、行程差、初值/融合入口位移、轴夹角、RMSE、内点比、袋径、D95、径向/轴向余量；缺失保留未知，负余量保留原值。
- 可达性只引用当前目标的 MoveIt/规划结果或账本到达证据，不从 allowed 或原点距离推导。图中的连接虚线为几何参考线，不是已验证的运动轨迹。
- 四项能力单独显示 VALID/INVALID/UNKNOWN。可达性 HTTP 响应保留 reachable + error_codes；有效半圈四元数 w=0 不再被改为 1。
- 模型、许可遵守同目标/同场景约束；显式批次不匹配的许可不绘制。动态预算条使用 DOM 样式更新，保持原有 CSP。

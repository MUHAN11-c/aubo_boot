# Web 调试功能验收清单

本清单是逐功能操作与证据要求，**不是测试通过记录**。执行者须在本轮输出目录另记通过、失败或未测及原因，附日志/截图/请求身份。2026-10-27 的早期运行结果见工作区 `runs/ros2_reconstruction_toggle_20261027/acceptance.json`；后续多轮、ACK 与 30 分钟补测在 `runs/web_30min_20261027/`。不能据此将清单所有分支标为通过。默认 mock、工具关闭、不 SetIO、不自动 ACK；mock 与浏览器协议模拟不能证明真机安全或 L7 采摘。启动与收尾命令见 [使用手册](debug-testing.md)。

## 1. 记录与连接

1. 导航与布局：打开总览、过程监控、单步调试、分析、五点力；核对当前导航、兼容 `/index.html`、键盘跳转和 320/390/768/1440 px。预期所有入口可达、焦点可见、主要控件无遮挡。证据：URL、窗口尺寸、截图、控制台；执行记录：填写本轮通过/失败/跳过及证据。
2. 默认 rosbridge：核对`/api/transport`元数据，确认页头传输与 WebSocket 回环端口、当前页面实际需要的投影订阅及有效 JSON（五点力只订 `web_force`，历史分析不建 WS）；参数查看标准 List/Get/Set 服务，业务查看现有服务/Action。预期不把 HTTP 静态页成功当作 ROS 在线。证据：WS 帧、状态时间、节点日志；执行记录：填写本轮通过/失败/跳过及证据。
3. HTTP 对照：先结束旧会话，以 `debug.html?transport=http` 打开；分别保存 OFF/ON 或协议测试。浏览器脚本五页fixture用`--transport http`（脚本默认），原生WS动作用`--transport rosbridge --only harvest --harvest`，不能把脚本默认当作页面默认。预期显式选择生效、语义与读回可对照；WS 故障不能自动重发到 HTTP。证据：URL、HTTP请求/响应、两组独立报告；执行记录：填写本轮通过/失败/跳过及证据。
4. 新鲜度：分别模拟 WS 断线、HTTP 不可用、传感器停流、后台再回前台。预期陈旧值有标记、普通操作禁用；取消入口保留不等于离线时取消已送达。WS 重连仅恢复订阅，不能重放服务/动作。证据：断线前后 request、帧时间、消息数及提示；执行记录：填写本轮通过/失败/跳过及证据。

## 2. 测试档、本轮设置与重建

1. 三档选择与载入：依次选择观察、L2、FULL 并载入。预期只改本地草稿，工具关闭，重建勾选保持原值；观察三使能关，L2/FULL执行抓取开，FULL才开套入。证据：草稿截图及无业务写消息；执行记录：填写本轮通过/失败/跳过及证据。
2. 六项开关：逐一检查运动放行、套入、执行、抓取、工具、本轮使用重建。只验证工具草稿联动，不确认开启工具。预期 grasp 带 execution、tool 带 execution/grasp、关闭运动清三使能；所有实际运行保持 tool=false。证据：草稿截图、读回；执行记录：填写本轮通过/失败/跳过及证据。
3. 写入/确认/重新读取：取消确认框、Escape、再次确认；确认后尝试编辑；有未应用参数草稿时重新读取。预期取消不写入，确认冻结设置，读写期间互斥；刷新当前值但保留草稿、重算差异。证据：消息计数、参数前后值、锁状态；执行记录：填写本轮通过/失败/跳过及证据。
4. 重建默认 OFF：空闲写入未勾选，读回 `skip=true/auto=false/allow_unrefined=true`；以新场景观察或干跑。预期不调用 Build，使用感知几何，旧重建模型不作当前证据。证据：三参数、request/epoch、阶段日志与模型提示；执行记录：填写本轮通过/失败/跳过及证据。
5. 重建 ON：空闲勾选并确认，读回 `skip=false/auto=true/allow_unrefined=false`，用新请求对照 OFF。预期走 Build/精化并保留质量拒绝，记录耗时、几何、修订和有效期；ON失败不能由OFF结果覆盖。证据：两组独立报告、原始模型与失败原因；执行记录：填写本轮通过/失败/跳过及证据。追加OFF→ON→OFF跨周期核对：ON有新Build/TSDF时，检查新GraspDecision实际进入臂侧缓存；周期收尾应释放旧unrefined钉扎并撤销旧几何/许可，身份与时效门继续生效。
6. 模式不一致：在协议模拟中构造三参数部分成功、读回不同或未知。预期不显示写入成功，不应用后续使能/开始任务，保留草稿，提示修复差异。证据：逐项返回、实际读回和拒绝提示；执行记录：填写本轮通过/失败/跳过及证据。
7. 未部署/未运行：模拟 `reconstruction_enabled=false`，或参数缺失/节点不运行。预期不能从页面启动节点，重建开启不可用；关闭模式正确说明节点缺失。节点存在/Active/自动采集/本轮 Build 分别核对。证据：startup facts、图与参数、禁用提示；执行记录：填写本轮通过/失败/跳过及证据。
8. 双侧使能：构造 supervisor 意图与 arm 实际不一致或超时。预期停止继续任务，不以勾选代替硬件写入端读回。证据：两侧三项值及时间；执行记录：填写本轮通过/失败/跳过及证据。

## 3. 单轮点选、队列与多轮

1. 启动单轮：观察档确认启动，等待新 epoch/锁定目标，然后停止。预期只建立场景与保持会话，不发抓取，不把零目标当成功。证据：新 request/epoch、图像时间、场景状态；执行记录：填写本轮通过/失败/跳过及证据。
2. 单果/多选：仅在已核对的 mock L2/FULL，点击顺序按钮、勾选目标后“抓取已勾选”，核对 priority。预期目标来自当前场景，顺序号不按 target_N 推测；重复点击不能被当查询。证据：目标列表、发送的 selection 与账本；执行记录：填写本轮通过/失败/跳过及证据。
3. 队列：mock 执行中再点选，随后换 epoch、模拟失败、未知或恢复等待。预期运行时排队，异常/换场清队列，旧目标不再下发。证据：队列截图、逐请求日志和发送次数；执行记录：填写本轮通过/失败/跳过及证据。
4. 多轮数字：分别输入空、0、31、小数、负数及合法 1–30。预期非法值本地拒绝，合法值确认框明确轮数；取消确认不发任务。证据：输入和请求计数；执行记录：填写本轮通过/失败/跳过及证据。
5. 多轮三策略：分别测试“每轮按顺序换一颗”“每轮第一颗”“每轮全部”。预期每轮新请求/场景，轮换按当前目标数取模，第一颗按 priority，全部核对每个目标；失败/未知/恢复锁阻止后续。证据：每轮 selection、target数、终态、账本；执行记录：填写本轮通过/失败/跳过及证据。
6. L2：只在 mock 或现场明确授权范围运行。预期 L2核验后停驻并等待人工恢复，不套入/切刀/自动 stow，后续队列停止。证据：同请求终态、几何和恢复状态；执行记录：填写本轮通过/失败/跳过及证据。
7. FULL：工具关闭，分别保存 ON/OFF 组。预期只有同请求 Action 成功、账本 SUCCEEDED且L6、已撤退、无终局恢复锁才记完整干跑通过；运行中临时接触恢复标志不误判终止。证据：完整阶段日志和账本；执行记录：填写本轮通过/失败/跳过及证据。L6不等于L7。

## 4. 恢复、取消与未知结果

1. 恢复 ACK：先用协议模拟验证旧批次已结算/中断（6/8）、恢复锁仍在、有效 state_seq、状态新鲜、动作空闲、臂不运行的组合；7 状态应先取消旧批次；确认框取消一次，再变化序号。预期条件不全禁用，旧序号拒绝，取消不发ACK；ACK不自动恢复队列/旧轨迹。证据：模拟输入、请求次数与新旧序号；执行记录：填写本轮通过/失败/跳过及证据。现场恢复仍由操作员核对，不做自动实机ACK。
2. 停止单轮/停止后续轮：分别在排队、运行、未知状态触发。预期清后续队列并按需发 CANCEL_NOW，按钮提示不是臂已停。证据：取消响应、Action终态、`action_active=false`、`running=false`；执行记录：填写本轮通过/失败/跳过及证据。
3. 监控取消执行/取消批次：核对确认框及作用范围，必要时按现场流程组合使用。预期取消受理与执行终态分别记录。证据：臂侧 cancel_cycle 或调度 CANCEL_NOW 的受理结果、对应请求身份与臂状态；执行记录：填写本轮通过/失败/跳过及证据。
4. HTTP错误：协议模拟200业务拒绝、202、400、207、423、500、503及网络超时。预期逐项拒绝可见、202/超时保留未知request、部分成功不假设回滚、不自动重试；取消入口仍保留。证据：原响应和页面提示；执行记录：填写本轮通过/失败/跳过及证据。
5. WS断线/服务拒绝/Action失败：在请求发送后中断WS，再重连。预期业务可能已执行，保留未知请求、不重放，先查同身份或取消；SDK 等待超时后，未知句柄应阻止重复提交，核对终态或取消并确认已停后再刷新；ROS逐项结果/Action终态直接可辨。证据：发送前后消息、日志和请求ID；执行记录：填写本轮通过/失败/跳过及证据。

## 5. 参数面板与证据身份

1. 搜索/过滤/草稿：按节点、名称、用途搜索，展开组、改值、只看待写、改回。预期当前与待写分明，数值1与1.0不伪增差异，刷新保留草稿。证据：差异计数和截图；执行记录：填写本轮通过/失败/跳过及证据。
2. 类型/范围：模拟空、非有限、整数小数、越界、非法枚举/布尔；节点离线/未声明。预期本地拒绝非法输入，缺节点只读，不拿默认值当读回。证据：无发送及校验消息；执行记录：填写本轮通过/失败/跳过及证据。
3. 应用/重读互斥：参数应用、本轮写入和两处重新读取交叉操作，模拟部分成功、拒绝与读回失败。预期锁持续到读回完成，仅全部一致报成功，失败保留草稿。证据：服务逐项结果、读回值、按钮锁；执行记录：填写本轮通过/失败/跳过及证据。
4. 运行期与部署：核对重启标记、参数来源；不把本次设置宣称写回源YAML。作业文件仅写本作业参数；`per_target_timeout_s`为goal字段，不能当节点参数。证据：实际ROS参数、goal和文件差异；执行记录：填写本轮通过/失败/跳过及证据。
5. 请求/旧模型：构造同 target_id 不同 epoch/request，过期 model_revision、valid_until 和旧账本。预期当前证据仅关联当前 run/request，OFF显示旧模型不作本轮证据，ON仍检查修订与有效性；allowed不替代臂侧授权。证据：完整身份链、页面和拒绝码；执行记录：填写本轮通过/失败/跳过及证据。
6. 审计边界：HTTP桥写入核对 debug_audit；WS调用另存ROS结果和会话记录。预期不声称HTTP运动门/审计覆盖WS。证据：传输方式、日志来源与实际文件；执行记录：填写本轮通过/失败/跳过及证据。

## 6. 监控、分析、力与结束

1. 总览/监控：检查图像源、暂停恢复、放大关闭、3D视角、实际TF工具方向、轨迹、目标顺序、时序、日志过滤/暂停；回拍照位仅在mock或另获授权时执行并确认。预期无TF不画默认方向，时间各自呈现，WebGL不可用仍有二维/数值。证据：截图、帧龄、TF与日志；执行记录：填写本轮通过/失败/跳过及证据。
2. 分析：解析本轮目录，再解析无效路径。预期明确失败并隐藏旧结果，历史分析不替换当前批次。证据：目录、响应与界面；执行记录：填写本轮通过/失败/跳过及证据。
3. 五点力：分别观察在线、源未启用、陈旧/断线，切换视角。预期陈旧清读数/CoP、切视角不复活旧帧，力显示不构成抓取许可。证据：源与接收时间、截图；执行记录：填写本轮通过/失败/跳过及证据。
4. 停栈：取消并核对终态，关三使能与运动放行并读回；结束浏览器、探针、采集、runner/launch，等待bag封口，检查每个自有进程退出码、记录可读性和端口/相机释放。预期无本轮残留，异常码保留失败；只处理自己PID。证据：report、owned_processes、bag info、pgrep及退出日志；执行记录：填写本轮通过/失败/跳过及证据。

## 7. 执行记录范围

每轮仅按实际证据填写通过、失败或未测。浏览器协议模拟、真实相机 + mock 干跑和真机验收分别记录；多轮策略全组合、人工恢复 ACK、工具执行与长测需要各自的独立证据。设计依据见 [使用手册第12节](debug-testing.md#12-ros-2-设计依据)。

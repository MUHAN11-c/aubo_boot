# 五点力验证与限制

## 1. 结论

- **分辨率/短期噪声**：好。12 位模块，370 g 处约 0.17 g/码，空载噪声 <2 码；
  单通道“力 = 8 点滤波 AD 经标定”的残差 0.10–0.28 g（最大 <1 g）。
- **绝对力/行程/五点精度**：未证明。残差是 STM32 模型自洽，不是对标准砝码/
  位移的误差；`travel_mm` 是 `力/66` 的反算，不是独立行程。
- **五点同步**：2026-10-22 真机 target_0 留下 1 次 4.26 s 五点同步记录；
  台架三组测试都没有五点同时。CoP/旋转控制仍须台架复验。

这是一次**真实同步记录**，但仍只有 1 次；不能据此定旋转符号、收敛或
长期重复性。

## 4. 还没证明的

| 项目 | 原因 |
|---|---|
| 绝对力误差 | 无标准砝码/测力计 |
| 同片重复性 / 迟滞 / 漂移 | 只有动态按压，未做静态升/降载与长时 |
| 片间 ±15% | 满行程 AD 差含安装/预紧/标定，不能分离 |
| 1.2 mm 预压 / 350 g / 5 mm | 代码 `GAP=0`，未做已知位移台架 |
| `mm` 精度 | 力反算，不是独立位移；不要当行程传感器 |
| 五点 CoP/旋转收敛 | 只有 1 次真机同步；台架 0 次五点同时 |
| 响应带宽 | 系统 100 Hz + 8 点 80 ms 滤波；传感器本身 <10 µs 未独立测 |

## 5. 下一步台架

1. 标准砝码/测力计逐通道 0/50/100/200/300/350/370 g，3 次；
2. 升/降载 0→370→0，测迟滞；
3. 1/2/5 mm 已知位移 + 力，定位 1.2 mm 预压与 350 g 口径；
4. 球/桃五点同时压 + 5° 旋转，≥10 次，验证 CoP 收敛、旋转符号与刀口位移；
5. 断线/悬空 + AD 阈值复验。

在这些完成前：单通道力/满行程/饱和可用；绝对力按 ±10% 容差；
5 mm 用机械臂位移 + 力双条件；CoP/力对准只用相对量。

# 安全红线（MUST）

> 生成快照（2026-10-13）。权威：[AGENTS.md](../AGENTS.md) 第 1–2 章、[测试指导 §0/§9](../src/peach/peach_system_tests/doc/testing.md)。

## MUST 红线

- **驱动栈只读**：`aubo_e5_hardware`、`aubo_e5_controllers`、`aubo_dashboard`、`aubo_e5.ros2_control.xacro`、`bringup.launch.py`、对应 `controllers.yaml`。应用包不改 `SystemInterface`（对齐 UR ROS2 Driver：应用仓 include bringup，不改驱动）。
- **bringup 不起 `aubo_dashboard`**，禁止调用该包；`auto_power_on=false`。上电、抱闸用示教器。
- **未授权不得真机运动或 SetIO。** 授权 = 人的口头/书面确认（操作员在 real 上发起 launch / 操作台指令），不是 8090 按钮、不是 yaml 里的 `true`。
- **硬件急停不经 ROS。** 示教器红钮 / 柜安全回路是 ISO 13850 急停。`RobotMoveStop`、取消 action、8090、DDS 话题都是**应用停轨**，不得称为 e-stop，也不得替代硬件急停。
- **关节序冻结**：`shoulder_joint, upperArm_joint, foreArm_joint, wrist1_joint, wrist2_joint, wrist3_joint`。顺序与 URDF / `joint_states` / 控制器 yaml 必须一致，否则透传点会拧腕。注意 `/joint_states` 的 name 数组常见**字母序**（`foreArm` 在 `shoulder` 前），消费者必须按名字对齐，禁止按下标当 MUST 序。
- **启动前后都 pgrep**：启动前 `pgrep -af 'ros2 launch|component_container|extrinsics_publisher|ros2 run'` 清残留；**测完即停**，任何测试/程序结束后必须退出并复核无残留（残留订户会占 FastDDS SHM、堵死 RELIABLE 大图流、TF 叠 child frame）。
- 不向 `build/` `install/` `log/` `_archive/` 提交。
- Python 用 `aubo_py3.12` venv；**numpy == 1.26.4**（Jazzy `cv_bridge` 按 numpy 1.x 编译，升 2.x ABI 崩）。
- 停轨 = 透传取消 + 硬件 `RobotMoveStop`（失败再 `robotMoveFastStop`）。
- 保护停止/急停后**禁止 resume 原轨迹**：取消 ROS goal → 人确认现场 → 示教器复位 → 重新下发。

## 安全三层模型

ROS 2 社区把安全分三层，混为一谈会把网页按钮当成急停：

| 层 | 做什么 | 不做 | 权威标准 |
|----|--------|------|----------|
| **功能安全**（柜与示教器） | 急停、保护停止、安全限速、使能装置 | 不跑在 DDS / Linux 用户态 | ISO 10218-1、IEC 60204-1（Cat 0/1/2）、ISO 13850、ISO/TS 15066 |
| **应用护栏**（ROS 2） | 使能默认关、命令仲裁、超时停、规划碰撞、lifecycle 心跳、诊断 | 不宣称 SIL / PLe / 功能安全认证 | Nav2 Collision Monitor、Autoware 命令门、Stretch runstop |
| **网络安全**（SROS2） | 加密、认证、权限 | 不是功能安全，挡不住臂已经在动 | ROS 2 DDS-Security |

IEC 60204-1 停止类别用词：**Cat 0** 立即断驱动电源；**Cat 1** 先受控停再断电；**Cat 2** 停但不断电。软件 `RobotMoveStop` 接近应用层受控停，不是 Cat 0/1。

## 应用护栏（现行实现）

1. **单一命令门 `ExecutionAuthority`**（`peach_arm` `cycle.cpp` `authorizeStage`）：
   - TRANSIT / PREGRASP = Active ∧ robotReady ∧ ¬cancel ∧ execution_enabled
   - CONTACT 再加 grasp_enabled ∧ GraspDecision 复检（目标 ID 对齐 + allowed）
   - TOOL 再加 tool_enabled ∧ 剪切能力 VALID ∧ 预备位残差过门
   - 所有运动 / IO 入口收敛此判定；新运动源必须进同一扇门，禁止旁路话题直写
2. **使能是运行时开关，默认全关**：`execution_enabled` / `execution.enabled` / `grasp.enabled` / `tool.enabled` 默认 false。意图源 = supervisor，广播 `/peach/batch/enables`（1 Hz 心跳），臂侧强制；缺心跳 5 s 回落本地参数权威。
3. **缺心跳 = 故障**：四托管节点已接 Nav2 bond（`bond_timeout` 默认 0 未开启进程死检）。
4. **套入/剪切唯一权威是 `GraspDecision.allowed`**：`allowed=false` 禁止套入/SetIO；令牌（Clearance）绑目标、`valid_until` 冻结不续签。
5. **指令有界**：move_group 全部 execute 收口 `boundedExecute`（默认 90 s 超时 + 取消探针）；TEM 已关闭（与透传控制器打架，UR Driver 主流做法）。
6. **刀/SetIO 与动臂同级危险**：8090 不得 SetIO；`tool.enabled` 默认 false。
7. **mock 不证明安全**：碰撞、电流、急停回路、刀、人在环只在真机 KEEP。

## 真机操作纪律

发真运动或 SetIO 之前：

- 示教器急停手能摸到；工作空间无人或已隔离
- 使能保持默认关，直到口头/书面授权
- 先 mock 再 real
- 冒烟确认：`/aubo_io_controller/robot_status` 须 `drives_powered=1 motion_possible=1`；`tf2_echo base_link tip` 报**不存在**（存在即旧实例污染）

急停按下之后：处理现场 → 示教器复位 → 取消并丢弃在途 goal → 重新授权再下发。

人在工作空间：示教常见 TCP ≤ 250 mm/s + 三位置使能装置；本仓有剪切手（套袋刀），按工业单元处理——人离开可达范围。

# 系统架构

> 生成快照（2026-10-13）。权威：[peach_bringup/doc/architecture.md](../src/peach/peach_bringup/doc/architecture.md)（825 行，含全部 C4 图与决策表）。

## 产品定位

- **愿景**：果园套袋桃采摘（室外光照、枝叶遮挡、将来底盘移动）。
- **现行产品**：固定座 AUBO E5 + RGB-D（launch 默认 `camera_frontend:=stereo`）。
- **近期成功标准**：`PREGRASP_ONLY` 门——到预抓取停住，不回 stow、不套入、不 SetIO；套入干跑须改 `execute_pregrasp_only=false`（默认 `tool.enabled=false`）。切断 + 撤退均确认才记采摘成功。
- **非目标**：launch 默认自动 RunHarvest；感知发运动；技能写账本；把 ROS / 8090 当功能安全急停。

## 五层 + 契约

```
契约层  peach_interfaces（IDL + manifest 双向核对）——全栈唯一通信语言
L0 传感驱动层  相机/臂驱动/TF                 【数据出生·只读红线】
L1 感知算法层  检测→身份→重建→融合→许可        【事实生产】
L2 决策调度层  联合约束选果→FSM→派发→账本      【决策生产】
L3 运动执行层  授权矩阵→笛卡尔规划→执行→IO     【动作生产】
L4 呈现层      RViz 稳定视图 + HTTP 作业票     【只读横切】
L5 过程数据层  会话 bag + 账本 + 预算回收审计   【只读横切】
```

不变量摘要：R1 跨层只经契约包；R2 数据流单向（L2→L3 IK 查询唯一例外）；R3 呈现不回写；R4 筛选维度归位（身份=L1、可行性=L2、渲染不发明筛选）；R5 纯核零 ROS；R6 运动收敛授权矩阵；R7 记录只增不删。

## 核心进程拓扑（C4 容器级）

- **`peach_harvester` brain —— 一进程三节点**：`peach_scene_perception_node`（看）+ `peach_target_reconstruction_node`（建）+ `peach_supervisor`（批），同一 MultiThreadedExecutor。图名/话题/lifecycle 按节点名管理不变。
- **`peach_arm`**（技能）：MoveIt/MTC 规划执行 + 工具 SetIO；唯一对透传控制器与 move_group 的运动客户端。
- **`peach_scene_obstacles`**：独立进程，Survey 触发点云→PlanningScene 障碍快照（仅相机受查，0035）。
- **相机前端**：`peach_stereo`（默认）/ `percipio_camera`，`/camera/*` 话题同构。
- **`peach_observability`**：8090 过程页 + 会话 bag。
- **`peach_lifecycle_manager`**（Nav2 `nav2_lifecycle_manager`）：名单硬编码 **场景 → 重建 → 技能 → 调度**；observability / vegetation 不进名单。
- **驱动**：ros2_control（mock=GenericSystem+标准 JTC；real=透传控制器）+ move_group + TF（RSP + extrinsics_publisher）。

调度（supervisor）是能力包批次动作的**唯一客户端**；8090 调试桥是唯一例外（须 `debug.motion_enabled`，留审计）。

## 整栈启动序列（harvest_system.launch.py）

1. `peach_stereo`（`camera_enabled:=true` 且前端为 stereo；须在 aubo bringup 之前——jazzy launch 参数全局沉降坑）
2. `peach_scene_obstacles`（`camera_enabled:=true`；同上须在 aubo include 之前）
3. `aubo_e5_bringup`——手臂 mock/real + 可选相机、手眼 TF、MoveIt
4. `serial_force`（`force_enabled` 默认 true；5 点力传感器）
5. `peach_harvester` brain（三节点，`require_managed_stack:=true`）
6. `peach_arm`
7. `peach_observability`（HTTP / 会话 bag）
8. `nav2_lifecycle_manager`（`bond_timeout` 默认 0；configure→activate 逐节点）
9. `peach_lifecycle_flag_bridge`（闩锁 `/peach/lifecycle/managed_nodes_activated`）
11. `peach_autostart_client`（仅 `autostart:=true`，默认关）

## 一批 RunHarvest 怎么跑（批次 FSM）

```
人工 RunHarvest → NAV 直通 NAV_OK（导航已归档）
  → SurveyScene（到全局拍照位 global_photo_pose 并复核关节静止）
  → BeginScene（重启收齐窗，scene_epoch+1）
  → WAIT_LOCK（观测世代对齐且锁定）
  → SELECT（联合约束选果：可达窗 ∩ 有效深度窗 ∩ 检测框面积次序；
           可达性权威 = CheckReachability 预抓取 IK）
  → 并行：BuildTargetModel + ExecuteTarget OBSERVE_ONLY
  → 默认 execute_pregrasp_only=true：ExecuteTarget PREGRASP_ONLY
      （停预抓取不 SetIO，人工目视评方向/定位 → ACK）
  → 回访 SurveyScene（不再 Begin）→ 下一颗
```

批次纯核 = `harvest_fsm.react(batch_state, event) → Reaction`（`peach_harvester/supervisor/harvest_fsm.py`）；节点禁止手写 `batch_state`。真运动后 `recovery_required` 须 ACK 才继续。

## ExecuteTarget 阶段序列（技能节点内）

```
stagePrepareCycle → (execution_enabled=false → 只规划终结)
  → stageAcquireViews（观察：最近短移只 LIN，覆盖达标或 maximum_moves 用尽）
  → stageFinalizeAndValidate
  → OBSERVE_ONLY 收口 / stageReconfirmTarget
  → stageMovePregrasp：先回拍照位 → 接近主路径 v4
      PTP 关节空间到中段点正下方（树冠外，滚转梯子 {0,±30°,±60°}）
      + 世界垂直 LIN 入冠 + 沿轴 LIN 对轴进入预抓取
  → stageVerifyPregrasp（残差增量修正，最多两次）
  → PREGRASP_ONLY → stageHoldPregrasp 停住
  → FULL：PlanSleeve → 套入（三档末端统一 MTC LIN）
      → SetIO → VerifyCut → 原路撤退 → 倒放回拍照位 → PTP harvest_stow
      → ReleasePayload → CompleteTarget
```

接近护栏：接触绕腕累计 **12 rad / 单轴 6.1 rad**（=URDF 满行程）；笛卡尔绕行比 2.6 / 偏离 0.32 m / 回退 0.12 m；TCP 姿态行程绝对 110°。观察 4 / 1.5 rad；拍照位 6 / 2.5 rad。近果 LIN 速度 0.05、自由空间 0.10 m/s。

## 接近约束四层（正交）

| 层 | 保护 | 机制 |
|----|------|------|
| ① 果实胶囊 | 果实 | 工具有限圆柱 vs 感知果实胶囊（半径=max(直径/2, 0.025)+0.01） |
| ② 反爬 | 果实 | TCP s ≤ 本段起点 max(s,0)+2 cm（锚果底） |
| ③ 场景障碍快照 | **仅相机** | `peach_scene_obstacles` 点云→BOX 对象（体素 0.06 m 先行+滤自身+滤精化目标）；不用 octomap updater（两轮翻车教训）；开关 `moveit.obstacle_guard_enabled` |
| ④ 近果降速+接触 | 果/硬件 | 套入/撤退 0.05 速度档；`ContactMonitor` 电流特征（默认关） |

## 透传链（real）

```
FollowJointTrajectory → AuboPassthroughTrajectoryController
  → GPIO trajectory_passthrough → AuboE5Hardware::write()
  → 4 ms 线程重采样 5 ms 点 → 接口板排空 succeed
```

技能不写关节；MoveIt 整条轨迹交透传控制器。取消走透传 abort + 柜侧停轨，不经 `aubo_dashboard`。

## TF 拓扑（唯一合法帧集，多出来的即旧实例污染、预检拒启）

```
/tf 动态   = base→shoulder→upperArm→foreArm→wrist1/2/3（robot_state_publisher）
/tf_static = world→base/table、wrist3→{camera_body,camera_link,tool_axis,tool_body_link}、
             tool_axis→{tcp,sleeve_mouth,cutting_plane}、camera_link→{color,depth}→各自 optical、
             camera_body→quick_changer_link
```

`extrinsics_publisher` 只发 `wrist3_Link→camera_link`（读 `aubo_hand_eye_calibration/hand_eye/active.yaml`），其余进 URDF。

TF 查询三分法（不要统一成一种）：

| 消费方 | 策略 |
|--------|------|
| 重建积分 | 图像时刻精确 TF；失败跳帧，**禁止 latest** |
| 感知几何 | 优先 stamp，失败 latest 并标 `tf_stale`；再失败不注册世界系 ID |
| 技能规划 | `TimePointZero` 当前状态 |

## 缝位（可替换算法）

现行多数算法直接构造；仅两处 dict 映射（UNWIND，新可替换算法默认 pluginlib）：

| 缝 | yaml 键 | 默认 |
|----|---------|------|
| 感知袋/果位姿管线 | `pipeline.bag_impl` / `fruit_impl` | `robust_bag` / `robust_fruit` |
| 重建柱/球 refitter | `refitter.cylinder_impl` / `sphere_impl` | `cylinder_refit` / `sphere_refit` |

## ID 与身份

四层正交：几何身份 `target_id`（χ²+匈牙利分配，clear 不复位计数器）→ 批次事务 `request_id→run_id→cycle_id` → 计划绑定 `plan_id+模型七元组` → 许可绑定 `clearance`（复用 target_id 不铸新 ID）。详细联动矩阵与已知缺口 ID-1~ID-5 见 bringup architecture.md「ID 与身份确定」节。

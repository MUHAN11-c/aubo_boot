# 接口契约

> 生成快照（2026-10-13）。权威：[peach_bringup/doc/io.md](../src/peach/peach_bringup/doc/io.md)（系统级）、[peach_interfaces/doc/io.md](../src/peach/peach_interfaces/doc/io.md)（IDL 总表）、[peach_interfaces/README.md](../src/peach/peach_interfaces/README.md)（字段级）。

## 总则

- 跨包**只走 `peach_interfaces`**（57 active + 5 reserved IDL）；柜侧 `RobotStatus` / `SetIO` 走 `aubo_msgs`。
- 清单 `interface_manifest.yaml` 双向核对：`python3 src/peach/peach_interfaces/scripts/check_interface_manifest.py`（已挂 CTest，改 IDL 忘改清单 colcon test 会红）。
- 作业目标只认调度 `~/state.target_id`；能力包不互发批次命令。
- QoS：传感 BEST_EFFORT + volatile；命令/动作/lifecycle RELIABLE；晚订户要最后一帧 → transient_local depth 1（`HarvestState`、`GraspDecision`、`/tf_static`）。
- 通道选择：连续可丢 → Topic；短 RPC → Service；长可取消 → Action；部署配置 → Parameter（**禁止**话题名当参数）。

## 动作（Action）

| 动作 | 服务端 | 含义 |
|------|--------|------|
| `RunHarvest` | `peach_harvester`（supervisor） | 开一批。goal：`request_id`（账本目录名，须唯一）、`scene_key`、`profile_id`、`intent`（0 PICK_ALL / 1 PICK_SELECTED / 2 SURVEY_ONLY）。采摘意图至少成功一颗才 `success` |
| `NavigateToWorksite` | （预留，导航包已归档） | 固定座调度直通 `NAV_OK`，不发动作 |
| `SurveyScene` | `peach_arm` | 去全局拍照位并复核关节静止；失败整批 `survey_failed` 不 Begin |
| `BuildTargetModel` | `peach_harvester`（vision） | 绑一颗、收合格机位后 finalize；与 OBSERVE_ONLY 并行 |
| `ExecuteTarget` | `peach_arm` | 对当前 target_id 跑一周期。`PREVIEW` 只规划 / `OBSERVE_ONLY` 补视角 / `PREGRASP_ONLY` 停预抓取（默认干跑）/ `FULL` 套入+刀+撤退 |
| `MoveTo`（`/peach_arm/move_to`） | `peach_arm` | KIND_NAMED（拍照位带原路返程）/ KIND_POSE（lin_only 只 LIN）；与接触周期互斥；supervisor 为消费方 |

## 服务（Service）

| 服务 | 服务端 | 含义 |
|------|--------|------|
| `BeginScene` | `peach_harvester`（vision） | 重启收齐窗，`scene_epoch`+1；仅首巡 Survey 到位后一次 |
| `CheckReachability` | `peach_arm` | 选果预检：预抓取 IK；`require_sleeve`（FULL）再检套入终点 IK + 沿轴笛卡尔。失败码 `no_ik` / `sleeve_no_ik` / `sleeve_no_cartesian`。不装配 MTC、不动臂 |
| `ControlTask` | `peach_harvester`（supervisor） | 人工控批：PAUSE / RESUME / CANCEL_NOW(4) / SKIP_TARGET / ACKNOWLEDGE_RECOVERY(6)；`expected_state_seq` 防乱序 |
| `SetEnables`（`/peach_supervisor/set_enables`） | supervisor | 操作台使能开关（execution→grasp→tool 依赖链校验）+ 广播审计 |
| `SetBatchPolicy`（`/peach_supervisor/set_batch_policy`） | supervisor | 运行期改批次策略 |
| `FireStep`（`/peach_supervisor/fire_step`） | supervisor | 单步；仅 PHOTO 接线（走 MoveTo），其余档占位即拒 |
| `nav2_msgs/srv/ManageLifecycleNodes`（`/peach_lifecycle_manager/manage_nodes`） | Nav2 管理器 | STARTUP/PAUSE/RESUME/RESET/SHUTDOWN；不发 RunHarvest |

## 关键话题（数据面）

| 话题 | 生产方 → 消费方 | 含义 |
|------|----------------|------|
| `/peach/perception/target_observations` | 感知 → 调度（选果）、重建、臂 | 场景里有哪些桃（真相流，含未确认） |
| `/peach/perception/initial_pose` | 感知 → 重建 | 单帧初值 |
| `/peach/reconstruction/grasp_decision` | 重建 → 臂（+调度闩锁缓存） | 融合几何 + 套入许可 `allowed`（唯一授权套入/剪切）；`valid_until` 冻结不续签（默认 120 s 窗） |
| `/peach/reconstruction/refined_*` / `tsdf_cloud` | 重建 → 臂 | 精化几何 / TSDF 点云 |
| `/peach_supervisor/state`（HarvestState） | 调度 → 感知/重建/臂/8090 | 批次唯一快照；`target_id` 是作业绑定 |
| `/peach_supervisor/events`（CanonicalEvent） | 调度 → 8090/bag | 可检索事件流，终局带 `failure_code` |
| `/peach/batch/enables`（Enables） | 调度 → 臂 | 使能广播（transient_local；Active 且 override 非空时 1 Hz 心跳；缺心跳 5 s 回落本地参数） |
| `/peach/lifecycle/managed_nodes_activated` | flag_bridge → 调度 | 闩锁：托管栈就绪 |
| `grasp_hypothesis`（技能 `~`） | 臂 → 8090 | 本周期抓取假说 |
| `/peach/scene/obstacles_refresh` | 调度 → scene_obstacles | Survey 成功触发障碍快照（transient_local） |

话题三类语义：**稳定流**（confirmed-only，进 RViz）markers / single_cloud / debug_image；**真相流**（全量，进记录与选果）detections / masks / observations / initial_pose；**模型流**（几何+许可）grasp_decision / refined_* / tsdf_cloud。

## 相机契约（/camera/*，前端二选一）

| 名字 | 含义 |
|------|------|
| `/camera/color/image_raw` | 彩色 |
| `/camera/depth/image_raw` | 配准深度（uint16 或 32FC1） |
| `/camera/color/camera_info` / `/camera/depth/camera_info` | 内参 K（配准后同 K） |
| `/camera/depth_registered/points` | 配准彩色点云（stereo 多一个 `confidence` FLOAT32 字段，point_step 24） |

- 前端选择：`camera_frontend:=stereo`（**默认**，主机单图案立体 ~13.5–13.7 FPS）/ `percipio`（设备端 18 图案 2.43 FPS，显式备用）/ `replay`（冻结 bag 重发，不起驱动）。stereo/percipio 相机连接互斥。
- 深度 uint16：**raw × `depth_scale_unit=0.25` = 毫米**（percipio）；32FC1 按米。
- 有效深度窗：`pipeline.min/max_depth_m` 0.3–1.5 m；有效=非 0 非 65535。禁止网络补深度。
- RGB-D 同步：`message_filters` ApproximateTime **slop 0.05 s**。
- 驱动 QoS `default`（RELIABLE）；订户手写 RELIABLE、depth=10。

## 改一个跨包字段的流程

1. 改 IDL 与字段注释（单位 m/rad/s，REP-103；光学系 `*_optical`）
2. 改接口 README 与 `interface_manifest.yaml`
3. 改 [peach_interfaces/doc/io.md](../src/peach/peach_interfaces/doc/io.md) 与 [系统 io](../src/peach/peach_bringup/doc/io.md)
4. **先** `colcon build --packages-select peach_interfaces`
5. 改各端 pub/sub；跑 `check_interface_manifest.py`
6. launch_testing 或 mock 冒烟证明两端仍连得上

不要只改一边源码让另一端"下次再跟"。

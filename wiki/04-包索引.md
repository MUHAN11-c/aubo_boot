# 包索引

> 生成快照（2026-10-13）。权威：[peach_bringup/doc/architecture.md](../src/peach/peach_bringup/doc/architecture.md) §3（含完整文件树）、各包 README。

工作区共 **31 个 colcon 包**，按目录分组：`src/peach/` = 现行采摘栈；`src/ivg/` = IVG/演示栈；`src/` 顶层 = 驱动与独立工具。peach2 十二包已于 2026-10-12 归档 `_archive/parked_2026-10-12/peach2/`，不再构建。

## 采摘应用包（src/peach/）

| 包 | 职责 | 不做什么 |
|----|------|----------|
| [`peach_interfaces`](../src/peach/peach_interfaces/README.md) | 跨包唯一 IDL（57 active + 5 预留）+ manifest 双向核对 | 不跑节点、不设算法参数 |
| [`peach_common`](../src/peach/peach_common/README.md) | Python 共享库（对齐 nav2_common）：yaml_params / param_rules / qos / paths 单源 | 不跑节点、不进 launch |
| [`peach_harvester`](../src/peach/peach_harvester/README.md) | 大脑一进程三节点：vision（场景观测 + 目标重建）+ supervisor（批次 FSM / 选果 / 视点两档 / 操作台服务 / 账本）+ `peach_scene_obstacles` 场景障碍快照独立进程 | 不发关节命令、不做 IK（问臂）；感知不选下一颗、不写账本 |
| [`peach_arm`](../src/peach/peach_arm/README.md) | 拍照、主动视点、质量/安全门、MTC 接触（`ExecutionAuthority` 授权矩阵）、工具 SetIO、撤退；GPL 参数单源 | 不写 `ledger.json`、不调重建 Trigger、不 `BeginScene`/`RunHarvest` |
| [`peach_bringup`](../src/peach/peach_bringup/README.md) | 整栈入口 `harvest_system.launch.py`、预检、nav2_lm 托管、autostart 客户端、生命周期桥 | 不含业务；launch 不自动开批 |
| [`peach_observability`](../src/peach/peach_observability/README.md) | 8090 过程页/单步调试、会话 bag（MCAP 限速）、`peach_bag_report`、启动自检 selfcheck | 不发运动 |
| [`peach_vegetation`](../src/peach/peach_vegetation/README.md) | GPU 枝/叶 2D 掩膜（Frangi + ExG/HSV，独立 launch） | 不写 PlanningScene、不进 harvest_system |
| [`peach_system_tests`](../src/peach/peach_system_tests/README.md) | isolated mock launch_testing（域 89–94/98）+ 回放塔 + perf 基线 + 冻结相机抓取 | 不进运行 launch |
| [`peach_stereo`](../src/peach/peach_stereo/README.md)（src/peach/） | 主机单图案立体深度相机前端（默认 `camera_frontend`，话题与 percipio 同构） | 不做感知业务；不改 percipio 驱动 |

节点角色速查：看=`peach_scene_perception_node`，建=`peach_target_reconstruction_node`，动=`peach_arm`，批=`peach_supervisor`，管=`peach_lifecycle_manager`（Nav2），监=`peach_observability`，枝叶=`peach_vegetation`，障碍快照=`peach_scene_obstacles`。

## 改哪边（快速路由）

| 要改什么 | 去哪 |
|----------|------|
| 消息字段 | `peach_interfaces`（先编接口包再编下游） |
| 检测/分割/TSDF/障碍快照 | `peach_harvester`（vision） |
| 视点/MTC/工具 IO 参数 | `peach_arm` |
| TCP/工具碰撞 mesh | `aubo_description`（勿改 ros2_control.xacro） |
| 末端工具切换 | launch `tool_profile` 参数（档案 `aubo_description/config/<profile>.yaml`，切换须整栈重启） |
| 拍照命名位姿 | `aubo_e5_moveit_config` SRDF |
| 批次顺序/选果/账本/lifecycle 名单 | `peach_harvester`（supervisor） |
| 轴向后撤 / 预抓取后撤 | `peach_harvester/config/grasp_standoffs.yaml`（单源注入） |
| 部署参数默认值 | 各包 `config/<节点>.yaml`（`peach_arm` 在 GPL `src/arm_parameters.yaml`） |
| 到位/Nav2 | 归档 `peach_navigation`（须书面授权恢复） |

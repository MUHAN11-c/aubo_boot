> 生成快照（2026-10-13）。权威：[AGENTS.md](../AGENTS.md) 第 9 章、[测试指导 §1/§2/§5/§15](../src/peach/peach_system_tests/doc/testing.md)。

## 环境

- ROS 2 Jazzy（apt）；Python 3.12 venv `aubo_py3.12/`（本机，不入库）；**numpy == 1.26.4**（cv_bridge ABI 硬约束，勿 pip 升级）。
- ROS 依赖走 apt（`rosdep install --from-paths src --ignore-src -r -y`）；其余第三方钉在 `requirements.txt`。
- venv 抢 PYTHONPATH 导致 cv_bridge 进错副本时：开新终端，`unset PYTHONPATH`，再依次 source Jazzy → 工作区 → venv。

```bash
cd /home/mu/Desktop/aubo_e5_jazzy_ws
source /opt/ros/jazzy/setup.bash
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
source install/setup.bash
source aubo_py3.12/bin/activate
export PYTHONPATH="$PWD/aubo_py3.12/lib/python3.12/site-packages:$PYTHONPATH"
python3 -c 'import numpy, cv_bridge; assert numpy.__version__ == "1.26.4"'
```

## 启动 / 停栈

```bash
# 启动前清残留（MUST）
pgrep -af 'ros2 launch|component_container|extrinsics_publisher|ros2 run'

# mock（默认）
ros2 launch peach_bringup harvest_system.launch.py hardware_mode:=mock camera_enabled:=false

# 真机（另需示教器上电 + 授权）
ros2 launch peach_bringup harvest_system.launch.py \
  hardware_mode:=real camera_enabled:=true robot_ip:=169.254.10.98
```

默认等价于 `hardware_mode:=mock camera_enabled:=false`：mock 臂（GenericSystem + 标准 JTC）、无相机、MoveIt+RViz2、手眼 TF、IMU、会话 bag 随栈开、**全部执行使能关**、不发 RunHarvest。

## launch 参数（harvest_system.launch.py）

| 参数 | 默认 | 说明 |
|------|------|------|
| `hardware_mode` | `mock` | 真机须显式 `real` |
| `robot_ip` | `169.254.10.98` | AUBO 控制器 IP；mock 不用 |
| `tool_profile` | `adaptive_shear_v1` | 末端工具档案；切换须整栈隔离重启 |
| `autostart` | `false` | true 时托管栈就绪+自检绿后自动发 RunHarvest（授权=操作员在 real 上发起 launch） |
| `moveit_enabled` / `rviz` | `true` / `true` | 无头/CI 传 `rviz:=false` |
| `camera_enabled` | `false` | 相机总开关 |
| `camera_frontend` | `stereo` | stereo（~13.5 FPS）/ percipio（2.43 FPS 备用）/ replay（冻结 bag） |
| `camera_ip` | `169.254.10.110` | stereo 前端使用 |
| `extrinsics_enabled` | `true` | 手眼外参静态 TF |
| `hand_eye_enabled` / `hand_eye_web_enabled` | `false` / `false` | 标定轮才开（8088 回环） |
| `imu_enabled` | `true` | USB IMU；无设备每 2 s 重试不挡栈 |
| `use_sim_time` | `false` | bag 回放 true + `--clock`；真机禁止误开 |
| `bond_timeout` | `0.0` | nav2_lm 进程死检窗口；0=关（现行） |
| `skip_reconstruction` | `false` | 真机 KEEP false；真感知下不可用 |
| `brain_params_overlay` | `''` | 冻结相机等测试 overlay |

## 运行期使能（软件门全关）

| 门 | 默认 | 语义 |
|----|------|------|
| `/peach_supervisor execution_enabled` | false | false 时 WAIT_LOCK 后直接结算，不派 ExecuteTarget |
| `/peach_arm execution.enabled` | false | 运动输出总门 |
| `/peach_arm grasp.enabled` | false | 停在 READY_FOR_GRASP |
| `/peach_arm tool.enabled` | false | 工具 IO 关；依赖链 execution→grasp→tool |
| `/peach_supervisor execute_pregrasp_only` | true | 接触段发 PREGRASP_ONLY（停预抓取等 ACK） |

使能是运行时开关：`ros2 param set` 或 `/peach_supervisor/set_enables` 服务（推荐，广播 `/peach/batch/enables` 并写审计）。mock 差异：不起 `aubo_io_controller`，launch 把 `execution.require_robot_status` 置 false。

## mock 冒烟最小集（发 RunHarvest 之前）

1. `ros2 control list_controllers`：JTC / 透传控制器 `active`
2. `ros2 topic echo /joint_states --once --qos-reliability best_effort`：六关节名与 MUST 序一致（name 数组常字母序）
3. `ros2 run tf2_ros tf2_echo world tcp`：有变换无跳变；`tf2_echo base_link tip` 应报**不存在**
4. lifecycle 四节点 `active`（场景→重建→技能→调度）
5. 相机开时：`ros2 topic hz /camera/color/image_raw`（帧率以 30 帧探针为准）
6. 启动自检：`ros2 topic echo /peach/observability/selfcheck_passed --once --qos-durability transient_local`（软门：红只呈现不拦手动 RunHarvest）

真机冒烟另加：示教器已上电、急停手能摸到、工作空间无人、`robot_status` 须 `drives_powered=1 motion_possible=1`、`tf2_echo wrist3_Link camera_link` 平移 ≈ `[0.045, 0.108, 0.002]`。

## 监控面（8090，纯调试客户端）

- `http://127.0.0.1:8090`：过程线 / 作业票 / 事件 / TCP 俯视 / 诊断聚合 / 单步调试（BeginScene/Survey/Build/Execute/RunHarvest/拍照位）
- 运动类调试须 `debug.motion_enabled`（默认 false → 423）；**不旁路 `ExecutionAuthority`**
- 其他端口：手眼标定 Web 8088（回环）、IVG 估姿 8089、IVG 演示网关 8095、rosbridge 9090、foxglove 8765

## 停栈与清进程（MUST）

1. 有在途批次先取消（`ControlTask` 命令 4 CANCEL_NOW），等终态
2. 关闭 execution/grasp/tool；终止探针、bag、回放与注入器
3. launch 终端 Ctrl+C；observability 报告收尾可能超 5 s 窗口，勿在写盘中强杀
4. 复核残留；按 PID 清（TERM → 2 s → KILL），不要宽泛 `pkill`

```bash
pgrep -af 'ros2 launch|component_container|extrinsics_publisher|ros2 run|ros2 bag|move_group|ros2_control_node|robot_state_publisher|peach_|lifecycle_manager|frozen_camera|parameter_bridge|gz sim'
```

一次性只读探针用 `timeout -s INT -k 3 5 ...` 包裹。别人的残留只报告不杀。

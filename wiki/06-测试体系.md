# 测试体系

> 生成快照（2026-10-13）。权威：[peach_system_tests/doc/testing.md](../src/peach/peach_system_tests/doc/testing.md)（419 行完整操作指导）。`colcon test` 绿 ≠ 采摘验收。

## 测试分层

| 层 | 工具 | 测什么 |
|----|------|--------|
| Lint | ament_lint_auto / flake8 / pep257 / uncrustify / cppcheck | 风格 |
| Unit | pytest（零 ROS 纯核）/ gtest（`peach_arm`） | FSM、几何、预算、协议 |
| Integration | `add_launch_test` 隔离域 mock | launch、lifecycle、话题接线、取消与退出 |
| 回放塔 | `test_replay_approach`（零 ROS 纯几何） | 接近/融合/护栏/包络回归门 |
| 冻结相机 | `run_frozen_grasp.py`（域 81） | 冻结 bag → 单视感知 → 抓一颗 |
| System | `sim_system_tests`（`src/peach_sim/`）+ 独立测试包 | 跨包端到端（mock/仿真） |
| Field | 真机 + bag + 命名 `request_id` | 方向/接触/IO 最终权威（KEEP） |

## 常用命令

```bash
# 能力包：核 + lint
colcon test --packages-select peach_common peach_interfaces peach_harvester \
  peach_arm peach_bringup peach_observability peach_vegetation peach_stereo \
  --return-code-on-test-failure
colcon test-result --verbose

# 接口清单核对
python3 src/peach/peach_interfaces/scripts/check_interface_manifest.py

# 集成组（先 ctest -N 确认名称命中）
colcon test --packages-select peach_system_tests --return-code-on-test-failure \
  --ctest-args -R '^test_test_(mock_launch|nav2_lifecycle_debug)[.]py$'
```

判读纪律：用 `--return-code-on-test-failure`；`No tests were found` 不算通过；skip 不能并入通过；筛选运行只更新被选 XML，勿把旧 XML 当本轮全测。

## 冻结相机一次感知 → 抓一颗（推荐仿真入口）

```bash
ros2 run peach_system_tests run_frozen_grasp.py    # 域 81；默认 bite_shear_v1、tool=false 干跑
```

- 数据源 `runs/peach_camera_capture_20260930/stereo_10s`（`--bag` 可改）；回放 stamp 改当前时刻，关节离开拍照位超 2 mrad 自动 `~/pause` 停发。
- 抓取时钟从 RunHarvest 受理起 **180 s**，到点取消判失败。
- 成功口径：至少一颗 `succeeded` 且回放已暂停；`tool=false` 干跑走套入、跳过 SetIO。
- 不要走 `skip_reconstruction`（真感知未精化直径为 0）。

## 回放塔（改接近/融合/护栏/包络必跑）

`test_replay_approach`：三层语料（现场真袋 14 例 + 分层 200 + 随机 100，seed 冻结）对照 `replay_baselines.json`。判定：`analytic_ok` 只许升不许降；`lin_chord_fail` 双侧容差 1；采样器/案册漂移须显式重封。护栏数学 `replay_oracle.py`（v4 公式）。

## 真机验收门（现行）

- **M1 单果观察**：同目标连续 3 次 PICK_ALL/OBSERVE_ONLY；独立机位 ≥ `min_views`、TSDF 点数 >0、refit ok、outcome=SUCCEEDED、失败有 failure_code。
- **单目标完整抓取**（运动、接触、不开工具）：观察覆盖达标或 moves 用尽；接近主路径 PTP+垂直入冠+沿轴；护栏 12/6.1 rad、绕行比 2.6/0.32/0.12、姿态 110°；无 SetIO；单目标 45–60 s。
- **P0–P9 软件门**（工具帧/袋模型/重建权威/预抓取/套入干跑/刀具/成功语义/导航/发现开窗）见 testing.md §10。
- **PREGRASP_ONLY 判定**：停预抓取后现场目视评筒口对轴、侧偏、剪切紫点；残差未过门也停住；终局 SUCCEEDED+recovery_required，ACK 后才再 Survey。
- 节拍现状：观察 6 视 33.5 s；接触干跑 45–60 s/果；fast 档方向目标 ≤20 s/果。

## 失败分层（先分类再归因）

| 现象 | 定性 |
|------|------|
| 无 joint_states / lifecycle 未 Active | 栈/环境失败；看预检残留、controllers、域与 QoS |
| `open3d`/`torch` ImportError | 依赖失败，不是 IK 失败 |
| 无 selfcheck 判定 | 未得到判定；不能按"没有 false"通过 |
| RViz Ogre/GLX 崩溃 | 显示端问题（无头用 `rviz:=false`） |
| bag 用例 skip | 未验证对应行为；数目不并入通过 |
| 缺权重 `best.pt`/`mobile_sam.pt` | 环境失败，不是规划失败 |

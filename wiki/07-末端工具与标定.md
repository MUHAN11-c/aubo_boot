## 三把剪切手（2026-09-28 替换两把套袋圆柱）

| 档案 | 特征 | TCP（wrist3 系） | D_inner | L_insert |
|------|------|------------------|---------|----------|
| `shear_v1` | 剪切手（手-相机位置试验版），开口 +Y（Rx(−90°)） | (0, 47.90, 151.07) mm | 0.080 | — |
| `bite_shear_v1` | 咬合式剪切手：双刀口对夹+喉道导轨；`sleeve_mouth`=identity | (0, 30.24, 165.5) mm | 0.104 | 0.030 |
| `adaptive_shear_v1`（**默认**） | 自适应剪切手+增量 IMU（MPU6050）：Ø136 圆盘+拉钩组 | (0, 47, 168.66) mm Rx(−90°) | 0.120 | 0.090 |

- 姿态语义三把同款：**TCP Z=开口、XY=刀口平面**；`cutting_plane`/`tcp` 与 `tool_axis` 同点；`tool_body_link` 挂 `wrist3_Link`（identity，载真实 CAD 网格）。
- 帧名三把共用冻结（SRDF/ACM/技能三点 TF 按名消费）；xacro `tool_profile` arg，未知名三支都不展开 → 缺 `tcp` 帧启动即失败（安全失败方向）。

## 档案是整栈单一事实源

`aubo_description/config/<profile>.yaml` 经 `peach_harvester.vision.tool_profiles` launch 期装载，注入：

- 感知 `tool.D_inner` / `tool.L_insert` / `tool.L_blade`
- 重建 `tool.budget.d_inner`（GraspDecision 许可数学）
- 各包 `tool.profile_id` 标签
- `peach_arm` `tool.d_inner_m` / `body_length_m` / `body_radius_m`（①层胶囊审查包络）
- `imu_follow` `insert.max_travel_m`（= L_insert）

**切换须整栈隔离重启**：`ros2 launch peach_bringup harvest_system.launch.py tool_profile:=bite_shear_v1`。RSP 与 MoveItConfigsBuilder 双展开必须同 arg，防 move_group 模型与 TF 分叉。改末端几何改 wrapper xacro 与档案 yaml 两处；不要改只读的 `aubo_e5.ros2_control.xacro`。

行为分支：仅 `adaptive_shear_v1` 在 FULL 接触窗开 imu_follow（enable→insert→剪切→retract→disable）；shear/bite 走 MTC LIN 套入/撤退，永不调用 imu_follow 服务。

## 手眼标定流程（会话工具，不进常驻栈）

```bash
ros2 launch aubo_e5_bringup bringup.launch.py hardware_mode:=real \
  robot_ip:=169.254.10.98 hand_eye_enabled:=true hand_eye_web_enabled:=true
# 浏览器仅回环 http://127.0.0.1:8088
ros2 service call /hand_eye_extrinsics_publisher/reload std_srvs/srv/Trigger {}
```

- **auto 档**（自动视点+内外参联合求解）：Web 台选 位姿来源=auto、求解目标=joint；或 CLI `ros2 action send_goal /hand_eye_calibration_server/run aubo_msgs/action/RunHandEyeCalibration "{pose_source: auto, solve_target: joint, return_to_start: true}"`。验收门：joint 总重投影 RMS ≤ 0.8 px；新旧外参差 mm 级。**会动真机，须单独授权。**
- 默认档仍是 poses 示教位姿。

## 彩色内参标定（棋盘 11x8 @20mm，需 X 显示）

```bash
# 先起相机前端
ros2 launch aubo_hand_eye_calibration intrinsics_calibration.launch.py
ros2 run aubo_hand_eye_calibration apply_intrinsics /tmp/calibrationdata.tar.gz
colcon build --packages-select percipio_camera   # 必须：launch 读 install 副本
ros2 topic echo /camera/color/camera_info --once # 核对 K 与文件一致
```

内参变更后手动更新 `peach_harvester/config/scene_perception.yaml` 的 `calibration_version`。原 vendored `camera_calibration` 包已于 2026-10-10 删除（`git show <提交>:src/camera_calibration/...` 可取回）。

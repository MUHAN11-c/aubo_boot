## 仿真下相机 TF 静态语义（重要）

相机为腕载（eye-in-hand）。mock 下外参静态 × 腕动态复合**不成立**——真相机/回放 bag 都是固定机位，移动 mock 臂造不出新相机机位。因此：相机相关 TF 按静态锚定理解，视点增量只在真机存在；mock 臂+真相机只用于相机出图/感知/TF 验证。

## IVG 旁路视觉抓取（三包，src/ivg/）

不进 `harvest_system` / lifecycle / peach 清单，不订 `peach_interfaces`；与采摘共用 L0 相机 / TF / MoveIt。2026-09-29 前沿化重构后为**分段流水线 + 可换后端**。

- **`ivg_pose_estimation`**（估姿，Web :8089）：Segmenter（`depth_band` 默认 / `rembg_u2net` / `mobile_sam`）→ Matcher（`geometric` 默认 / `dinov2_template` DINOv2 嵌入检索）→ pose 求解。`EstimatePose` 带 Header（stamp=采集时刻，TF 同 stamp）。写端点须 `vpe_auth` cookie 或 `X-Auth-Token`（token 见启动日志 / `VPE_WEB_TOKEN`）；运动/IO HTTP 一律 501。配置单源 `config/pose_estimation.yaml`。
- **`ivg_graspnet`**（抓取）：`backends/` 注册表双后端——`graspnet_torch`（默认，vendored 纯 torch，**不用 AnyGrasp 许可证**）+ `contact_graspnet`（vendored，NVIDIA 非商用系许可）。耦合超参随权重 manifest `checkpoint-rs.yaml`；`publish_grasps_client` 有 opt-in 使能门 `require_enable`；MoveIt 超时自动 cancel。真机运动须另授权。
- **`ivg_sim`**（抓取验证仿真，域 98）：Gazebo 桌面场景（10 YCB + 可调 rgbd）+ `score_grasps` GT 评分 + `execute_grasp.py` 机械臂执行闭环（MoveItPy OMPL transit + KDL IK 逐路点 + 夹爪开合）。YCB meshes 不入库（`fetch_ycb.sh` 恢复）。已知限制：Allegro 四指独立伺服先触单侧会推飞目标，mimic 联动方案已核实待实施。

评估基线：dinov2 检索 14/14；分割学习档棚拍口径未达标 → 默认档不切换，待现场快照轮。

## IVG 演示栈（四包，默认域 96）

入口 `ros2 launch ivg_demo_services demo_services.launch.py`（须先起 move_group 与控制器栈；每个终端自行 `export ROS_DOMAIN_ID=96`，默认 mock；`io_simulated:=true` 时 IO 旁路）。原 `scripts/start_ivg_demo.sh` 已于 2026-10-10 退役。

| 包 | 作用 |
|----|------|
| `ivg_demo_services` | move_service（手动运动/状态/IO 读/使能/速度）+ grasp_trigger（单次/循环抓取）+ system_monitor 心跳 |
| `latte_backend` | 5 步咖啡拉花工作流 + 心形轨迹纯核（MSLA 参数化）+ 奶缸嘴标定 + DO2/DO4 IO 桥 |
| `tool_changer` | 数据驱动取/放轨迹（tools.yaml）+ PlanningScene 附着/脱离 + 前端 URDF 换装（attach_frame 默认 quick_changer_link） |
| `aubo_ros2_web_dashboard` | FastAPI 纯代理网关 **8095** + 8 MPA 面板（rosbridge 9090 / foxglove 8765 / web_video 8089） |

**IVG/peach 隔离裁定（2026-09-30）**：IVG 资产只落 IVG 包，不向共享包（aubo_description / aubo_e5_moveit_config / peach_*）添加任何 IVG 专有内容；peach 现役域 77 与演示栈 96 勿同域混跑；URDF 换装改 TF 树期间禁止 peach 预检/整栈同域启动。共享面仅限通用基础设施（bringup/moveit 控制器栈、aubo_dashboard、aubo_msgs）。8090 仍归 peach_observability。

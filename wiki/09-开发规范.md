# 开发规范

> 生成快照（2026-10-13）。权威：[AGENTS.md](../AGENTS.md) 第 3–7 章（全文规则）。

## 演化判据（MUST / DEFAULT / KEEP / SNAPSHOT / UNWIND）

- **MUST**：安全、发行版/ABI、测完清进程、不提交 build/install/log/_archive。
- **DEFAULT**：ROS 2 官方与优秀 GitHub 主流（UR ROS2 Driver、MoveIt 2、Nav2、Autoware、ros2_control_demos、TurtleBot 4、OSU apple-harvest）。
- **KEEP**：仅当完美适配当前真机/产品——①约束来自这台机器人/这套工艺（AUBO SDK、关节序、Percipio 停走节拍、套袋刀、cv_bridge ABI）②本地做法是表达该约束的最小方式 ③不阻止主流 API。
- **SNAPSHOT**：包级活文档里现在跑什么，不是"永远必须这样"。
- **UNWIND**：不是完美适配的历史偏好（禁 pluginlib、禁 launch_testing 等），改到那一块就改成主流，禁止用"现行 architecture 这么写的"挡回去。

**现行实现和设计默认视为可能不合理**，对照主流之后再动手。

## 编写前必须检索（硬门）

找不到高质量现成模式，不准发明第二套。顺序：Jazzy 官方文档 → REP → 同分支教程与驱动（ros2_control_demos / moveit2_tutorials / navigation2 等）→ 应用栈范例（Autoware / TB4 / Stretch / OSU）→ 本仓 SNAPSHOT 与同职责现有包。

**用库之前的全量阅读**：文档（限制、线程模型、QoS、异常）+ 源码（公有 API、默认参数、错误返回）都读完再调；文档与源码不一致以源码为准；只写薄适配层。

典型应优先用、禁止重写：

| 问题 | 用 | 不要 |
|------|----|------|
| 坐标变换 | tf2_ros Buffer/TransformListener | 手写变换树 |
| 多话题时间同步 | message_filters | 自研对队列 |
| 图像传输 | image_transport / cv_bridge | 自研压缩话题 |
| 诊断 | diagnostic_updater + /diagnostics | 自研 HTTP 报健康 |
| 轨迹 | JTC / MoveIt | 应用节点重采样关节点 |
| 滤波/几何 | Eigen / tf2 / scipy | 手写四元数乘法 |
| 生命周期管理 | nav2 lifecycle_manager + bond | 无心跳"激活名单" |

## 包布局

标准树（新包必须）：`package.xml`（format 3）+ `CMakeLists.txt`/`setup.py` + `README.md` + `include/<pkg>/` + `src/` 或 `<pkg>/`（Python，模块名=包名）+ `msg/srv/action`（仅接口包）+ `launch/` + `config/` + `test/` + `doc/`。

- 依赖单向：interfaces ← 能力包；能力包之间禁止 import 业务模块；驱动包不被应用改
- 标准消息优先（geometry_msgs/sensor_msgs/vision_msgs…）；自定义 IDL 仅当标准不够
- 纯核零 ROS（可单测）；节点只做 I/O 接线：`decode → process → publish`
- 失败可定位：稳定 `failure_code`；规划失败不执行残缺轨迹
- 一仓多包 `src/<pkg>/`；按子工作空间分组（`src/peach/`、`src/ivg/`），包名/图名不变

## 通信

- Topic=连续可丢；Service=短 RPC；Action=长可取消；Parameter=部署配置（**禁止话题名当参数**，用相对名 + remap）
- 传感 BEST_EFFORT+volatile；命令/动作/lifecycle RELIABLE；`/tf_static` transient_local；禁止第二套 TF 广播器叠同一 child frame
- 图名小写+下划线；节点私有 `~/`；带位姿/图像的消息必须 `std_msgs/Header`
- 单位 REP-103（m/rad/s）；光学系 `*_optical`；深度 uint16 毫米是 SNAPSHOT 例外（本仓 raw×0.25=mm），新字段优先米
- QoS 两端必须兼容：怀疑没连上先 `ros2 topic info -v`，不要先改算法

## 参数体系（现行）

- **Python peach 节点**：`config/<节点>.yaml` 全量清单（部署事实源，nav2 式）+ `yaml_params.attach(node)` 一行声明（实现单源 `peach_common`）。数值/白名单校验在各节点 params 模块 `_RULES`（启动期非法拒启、运行期非法 set 即拒）；跨字段窗走 `preview=`。
- **`peach_arm` C++**：generate_parameter_library 单源 `src/arm_parameters.yaml` → `arm_parameters.hpp`（空闲态重载、运动中拒改、execution→grasp→tool 依赖链）。
- 生效顺序：yaml 默认 → launch overlay（grasp_standoffs / 工具档案注入）→ 运行期 `ros2 param set`。
- 键名冻结（真机命令/文档零破坏）。新 C++ 包默认 GPL；Python 不要再引入第三套参数框架。

## 代码风格

- C++：Jazzy **C++17**；Google 风格改版；行宽 100；头 `.hpp` 实现 `.cpp`；`override`/`nullptr`/`make_unique`；优先 `std::`，避免 Boost
- Python：PEP8；新代码带类型注解
- lint 进 `BUILD_TESTING`（ament_lint_auto）；不关 lint 过门
- 日志走节点 logger；热路径节流（THROTTLE）；失败码+关键标量足够复盘，不打整帧点云
- 回调：大消息 `unique_ptr<Msg>`；重活放有界 worker（`BoundedWorker` drop_oldest 是范例），不要在默认互斥组做长 CPU
- Executor：默认组 MutuallyExclusive；同步 service.call + 订阅同组=自死锁，拆 callback group
- 时间：`this->get_clock()`；仿真全图 `use_sim_time`

## 缝位

- 新可替换算法默认 **pluginlib**；默认可仍直接构造一个实现
- 现行仅两处 dict 缝（`pipeline.*_impl` / `refitter.*_impl`）是 SNAPSHOT/UNWIND，禁止再扩平行注册表
- 高带宽感知优先 composable + intra-process（平台阻断已核实：Python 无组件容器，进程隔离+bond 是当前可达上限）

## 文档纪律

- 改行为 = 源码 + 对应活文档**同一轮**（bringup 系统文档 + 各包 doc/）
- 注释不得与活文档或源码打架；发现不一致两边一起改
- SNAPSHOT 用现在时；DEFAULT 用祈使；禁止把 SNAPSHOT 写成红线
- 不新增仓库级活文档；`docs/` 只留 v1/v2 方案书

## 常见反模式（看到就改主流）

| 反模式 | 改成 |
|--------|------|
| "architecture 写了不上 pluginlib" | 新缝 pluginlib（决策 0002 是 UNWIND） |
| "禁止 launch_testing / gtest" | 官方测试塔（决策 0006 是 UNWIND） |

| 8090 直接 SetIO | ExecutionAuthority |
| 把 ROS 话题叫 e-stop | 硬件急停 |
| 保护停止后 resume 原程序 | 取消 goal → 确认 → 重新下发 |
| 感知 import 技能模块 | 只走 IDL |

| 测完不杀进程 | 停栈 + pgrep 复核（MUST） |

## 改前 / 改后清单

改前：① 是否碰驱动/真机/IO ② 官方主流做法是什么 ③ 本地做法是否完美适配 ④ 能否用标准 msg ⑤ 落在标准树哪层 ⑥ 测试落在金字塔哪层。

改后：① lint+单测绿 ② 接口改了则 manifest 绿 ③ mock 冒烟或 launch_testing ④ 同轮活文档 ⑤ 未授权不动真机 ⑥ pgrep 无残留。

# 决策与演化

> 生成快照（2026-10-13）。权威：[AGENTS.md](../AGENTS.md) 第 11–12 章、[peach_bringup/doc/architecture.md](../src/peach/peach_bringup/doc/architecture.md) §7（决策表全文 0001–0039）。

## KEEP（完美适配当前真机/产品）

- Jazzy + C++17；numpy 1.26.4（cv_bridge ABI）
- AUBO 关节序冻结；驱动九包只读；bringup 不起 dashboard；示教器上电（不远程 power_on）
- 未授权不动臂/SetIO；硬件急停不经 ROS；autostart 是部署参数（默认关）；使能=操作台运行时开关；`execute_pregrasp_only` 默认 true
- 保护停止/急停后不 resume 原轨迹；停轨=应用层 `RobotMoveStop`
- mock = `mock_components/GenericSystem` + 标准 JTC（与 UR 主流一致）
- 重建积分精确 stamp TF；停走式相机节拍（percipio 2.4–2.5 FPS / stereo ~13.5）
- 套袋工艺：`GraspDecision.allowed` 许可令牌族只授权套入/剪切；`PREGRASP_ONLY` 不要求许可
- `harvest_fsm.react` 纯核；调度三订阅（target_observations / grasp_decision 令牌缓存 / managed_nodes_activated）
- 感知不发运动、不选下一颗、不写 ledger；技能不写 ledger、不调重建 Trigger
- 8090 作为纯调试客户端（无令牌；运动另需 `debug.motion_enabled`）
- 技能去 BT.CPP、显式 `stages.cpp`（接触序列用 MTC stage）
- `message_filters` slop 0.05 s RGB-D 同步；C++ lint 以 uncrustify 为准
- IVG 不进 harvest_system、navigation 归档：产品范围
- 真机仍是套袋方向/接触的最终权威

## UNWIND（历史偏好，改到即改主流）

- 不上 pluginlib / 只 dict `*.impl` → 新可替换算法默认 pluginlib
- 禁止 gtest / launch_testing / 采摘仿真测（决策 0006）→ 官方测试塔
- lifecycle bond 已接线但 `bond_timeout` 默认 0 未开进程死检
- peach 节点不用 composition（平台阻断已核实：Python 无组件容器——进程隔离+bond 是可达上限）
- 无 Gazebo/Isaac 系统测（`peach_sim` 已补场景层，`gz_ros2_control` 未接）
- 8090 若越权成第二控制面（纯调试客户端仍 KEEP）
- 腕轴 `ContactMonitor` 默认关，不能代替柜急停
- `imu_follow` 开运动时旁路 `authorizeStage`（默认门关；真机须另授权）

## 已知缺口（不破安全主链，修复另轮裁定）

- ID-2/3/4/5：plan 契约三软点、ModelSnapshot 不绑 ctx.target_id、臂 SurveyScene result 恒 0、`harvest_status` 措辞级失真（详见 bringup architecture「ID 与身份确定」节）
- e1 exit_codes：SIGINT 时有在途 ExecuteTarget 仍 `terminate`（detached 线程竞态，决策 0038 形态②挂账）
- RESET 后再 STARTUP 在感知节点 configure 返回 false（2026-10-12 复核，记录失败后停栈重启）
- stereo 下观察第二视角集不上（ICP 27.3 mm 界/漂移 431 mm/worker 满队）——感知轮议题
- 切断确认：SetIO ACK ≠ `cut_confirmed`；刀具 DI `/aubo_io_controller/io_states` 预留未接线；`tool.enabled=true` 未确认终局 FAILED/CUT_FEEDBACK_TIMEOUT

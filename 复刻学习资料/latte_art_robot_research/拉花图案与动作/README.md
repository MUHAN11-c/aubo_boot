## 一、拉花的三个物理阶段

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  阶段1: 融合  │    │ 阶段2: 成形  │    │ 阶段3: 收尾  │
│  (Mixing)    │───→│  (Drawing)   │───→│ (Finishing)  │
└──────────────┘    └──────────────┘    └──────────────┘
  奶缸高位 5-8cm      奶缸贴近液面          奶缸上提 8cm+
  细流注入             大流量注入            细流拉线
  奶泡沉底融合         奶泡浮于表面          穿过图案中心
  30% 时间             50-60% 时间           10-20% 时间
```

### 每个阶段的物理原理

| 阶段 | 高度 | 流速 | 物理原理 | 目的 |
|------|------|------|---------|------|
| 融合 | 液面+7.6cm (3英寸) 以上 | 细流 | 奶泡以较高动能冲入，穿透 crema 沉入咖啡底层 | 奶咖融合，形成深棕色基底 |
| 成形 | 液面+0.6cm (1/4英寸) 以内 | 大流量且逐渐递增 | 奶泡动能不足穿透 crema，白色奶泡浮于表面 | 绘制白色图案 |
| 收尾 | 抬高到7.6cm (3英寸) 标记以上 | 细流慢速 | 奶流变细，在图案中穿过一条细线 | 图案收尾修饰 |
| ⚠️ 避免 | 液面+2.5cm (1英寸) 左右 | - | 部分奶泡沉入部分浮面 | 产生浑浊米色 (beige)，破坏对比度 |

## 二、常见拉花图案的动作分解

### 1. 心形 (Heart) — 基础图案

```
  ┌─────────────────────────────────┐
  │ 融合: 奶缸高位，杯中心偏前注入      │
  │                                   │
  │     杯前部                         │
  │  ╭───────╮                        │
  │  │  ●    │  ← 定点注入             │
  │  │  ↓    │  ← 前推 1-2cm           │
  │  │ /  \  │  ← 上提 + 拉线收尾      │
  │  ╰───────╯                        │
  │     杯后部                         │
  └─────────────────────────────────┘

动作序列:
  1. 定点注入: 奶缸固定于杯前1/3处, 贴近液面, 注入白色奶泡
  2. 前推: 奶缸向前(杯后方向)推约1-2cm, 白色圆点被推成心形
  3. 上提收尾: 奶缸上提同时拉回杯前, 穿过白色区域中心
```

**轨迹参数**:
```
定点XY: (杯中心X, 杯中心Y + radius*0.3)
前推距离: radius * 0.25 (约1cm)
前推方向: Y轴正方向(杯后)
收尾方向: Z轴上升 + Y轴回拉
```

### 2. 树叶 / Rosetta — 最经典的拉花图案

```
  ┌─────────────────────────────────┐
  │ 融合: 奶缸高位，杯前部注入          │
  │                                   │
  │     杯前部                         │
  │  ╭───────╮                        │
  │  │ ∿∿∿∿  │  ← 左右摆动(5Hz)       │
  │  │  ∿∿∿  │  ← 同时缓慢后移         │
  │  │   ∿   │  ← 摆动幅度递减          │
  │  │   ↑   │  ← 中线前推收尾          │
  │  ╰───────╯                        │
  │     杯后部                         │
  └─────────────────────────────────┘

动作序列:
  1. 奶缸从杯前1/3处开始
  2. 左右高频摆动 (3-6Hz) + 缓慢向后移动
  3. 摆动幅度逐渐减小 (从杯前到杯后, 空间变窄)
  4. 收尾: 沿中轴线从后往前推回, 穿过所有叶片
```

**轨迹参数**:
```
X(t) = A·sin(2π·f·t)    A: 5-10mm(前) → 2-3mm(后)
                         f: 4-6Hz
Y(t) = V_y·t             V_y: 2-5mm/s (缓慢后移)
Z(t) = 液面+1.5cm        恒定

收尾: X=0 (中轴), Y从后往前, Z上提
```

### 3. 郁金香 (Tulip) — 分层叠层图案

```
  ┌─────────────────────────────────┐
  │                                   │
  │     杯前部                         │
  │  ╭───────╮                        │
  │  │  ●3●  │  ← 第3层               │
  │  │  ↓2   │                        │
  │  │ ● →   │  ← 第2层(穿过第1层)     │
  │  │  ●1   │  ← 第1层               │
  │  │   ↑   │  ← 收尾拉线             │
  │  ╰───────╯                        │
  │     杯后部                         │
  └─────────────────────────────────┘

动作序列:
  1. 第1层: 杯最前方定点注入 → 前推
  2. 停顿, 奶缸稍后移
  3. 第2层: 在第1层后方定点注入 → 前推穿过第1层
  4. 第3层: 在第2层后方定点注入 → 前推穿过第1、2层
  5. ... (通常3-5层)
  6. 收尾: 从最后一层位置拉线穿过所有层
```

**轨迹参数**:
```
每层: {
  起始Y: Y_base - i * spacing     (spacing ≈ 8mm)
  前推距离: push_distance + i * increment
  耗时: 每层约 1-1.5 秒
}
```

### 4. 天鹅 (Swan) — 进阶组合图案

```
  ┌─────────────────────────────────┐
  │     杯前部                         │
  │  ╭───────╮                        │
  │  │ ∿∿    │ ← 身体 (Rosetta)      │
  │  │   ╲   │ ← 颈部 (弧线)          │
  │  │    ○  │ ← 头部 (小圆)          │
  │  │   ╱   │ ← 喙 (短线)           │
  │  ╰───────╯                        │
  │     杯后部                         │
  └─────────────────────────────────┘

动作序列:
  1. 身体: 做一次 Rosetta (摆动+后移)
  2. 颈部: 从身体末端弧线拉回杯前
  3. 头部: 在杯前画一个小圆
  4. 喙部: 从头部拉出一条短弧线
```

## 四、奶泡质量对轨迹的影响

该B站视频重点讲解了牛奶科学，这里映射为机械臂参数约束：

| 奶泡状态 | 视觉特征 | 对轨迹的影响 |
|---------|---------|-------------|
| 奶泡过厚 (干奶泡) | 流动性差, 白色块状 | 成形阶段需要**更低高度** (<1cm), 更慢速度 |
| 奶泡适中 (微泡) | 流动性好, 光滑光泽 | 标准参数即可, 容错度高 |
| 奶泡过薄 (湿奶泡) | 流动性过强, 不够白 | 需要**更快摆动频率**来产生图案对比度 |
| 奶泡分层 | 上层干下层湿 | 倒奶时需**倾斜角度更大**, 让湿奶泡先流出融合 |

**建议**: 在机械臂系统中加入视觉反馈，实时检测奶泡流出状态，动态调整成形高度和摆动频率。

## 五、拉花失败模式分析 (从人类教程推断机械臂常见问题)

| 失败现象 | 人类原因 | 机械臂对应问题 | 解决方案 |
|---------|---------|--------------|---------|
| 图案模糊 | 奶泡过薄/倒奶太快 | 速度剖面过陡 | 降低最大速度, 加入 jerk 约束 |
| 白色不浮现 | 奶缸距液面过高 | Z 高度偏差 | 视觉反馈校准液面高度 |
| 图案不对称 | 摆动左右不等幅 | 机械臂X轴伺服误差 | 校准 X 轴零点, 检查传动间隙 |
| 图案变形 | 手抖/晃动 | 末端振动/共振 | 加装减振, 降低加速度 |
| 收尾线歪 | 手不稳 | 笛卡尔路径规划失败 | 检查 IK 解连续性 |
| 液体溅出 | 倒奶角度过大 | 奶缸倾斜角过大 | 限制 pitch 角 < 60° |

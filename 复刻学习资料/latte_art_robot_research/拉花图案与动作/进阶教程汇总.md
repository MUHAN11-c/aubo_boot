## 一、多源参数对比（关键差异）

不同教程对同一参数的描述存在差异，以下是交叉对比：

| 参数 | Sunergos (原视频) | Clive Coffee | latteartguide.com | Perfect Daily Grind |
|------|------------------|-------------|-------------------|-------------------|
| 融合高度 | 3 英寸 (7.6cm) 以上 | **4-5 英寸** (10-12cm) | 高处倒入 | 高处倒入 |
| 成形高度 | 1/4 英寸 (0.6cm) 以内 | 贴近液面 | 抵住杯沿 | 尽量贴近液面 |
| 奶流粗细 | — | 铅笔粗细 | 中速 | — |
| 填杯至 | — | 过半杯 | **3/4 满** | 约一半杯量 |
| 牛奶打圈 | — | — | **5-10 圈** 至湿漆状 | — |
| 最终奶温 | 140°F (60°C) | — | **122°F (50°C)** | 55-65°C (139-149°F) |
| 进气截止温度 | 100°F (37°C) | — | — | **33°C (90°F)** |
| 作图流速 | 持续递增 | 保持恒定 | 中速, 太慢泡沫无法释出 | — |
| Rosetta 后移 | 缓慢向后拉 | 从远端往近端 | 稳定回拉 + **摆幅递减** | — |

### 关键差异分析

**融合高度 (3" vs 4-5")**:
- Sunergos: 3 英寸以上即可让奶泡沉底
- Clive Coffee: 4-5 英寸更安全, 有更大的容错空间
- **机械臂建议**: 取 8-10cm 作为默认融合高度

**成形高度**:
- 所有来源一致: **越近越好**, 抵住杯沿最佳
- **机械臂参数**: Z = 液面 + 0.3-0.6cm (考虑机械臂精度, 0.5mm 可能太激进, 建议 3-5mm)

**最终温度差异**:
- Sunergos (60°C) vs latteartguide (50°C): 差异可能在于杯型
- **50°C** 的奶更顺滑, 适合复杂拉花; **60°C** 更甜, 适合饮用
- **机械臂**: 奶温由打奶泡机控制, 机械臂只需在适当时机使用

## 二、四种图案的详细动作分解 (来自 latteartguide.com)

### 心形 (Heart) — 五步法

```
Step 1: 旋转奶缸 5-10 圈 → 至"湿漆"顺滑状态
Step 2: 打圈方式轻倒 → 填至约 3/4 满
Step 3: 奶缸贴近/抵住杯沿 → 固定中心点持续左右摆动
         → 直到出现圆形/苹果状白色图案
Step 4: 圆形形成后 → 竖直抬起奶缸
         → "抬升产生的吸力会让圆形顶部形成弧线" → 心形顶部
Step 5: 保持奶流 → 从杯一侧划向另一侧 → 完成
```

**机械臂关键参数**:
- Step 3 的"固定中心点左右摆动"：这是产生圆形白色底的关键
- Step 4 的"竖直抬起"：Z 轴快速上升，奶流变细 → 产生心形凹陷顶部
- Step 5 的"划穿"：Z 轴保持高位 + XY 直线运动

### 郁金香 (Tulip) — 同心堆叠法

```
核心理念: "一系列心形叠在一起"

Step 1: 奶缸抵杯近端 → 稳定左右摇摆 → 推向远端
        → 远端形成半圆后 → 停止倒奶 + 抬升
Step 2: 奶缸回杯近端 → 重复摇摆 → 在第一个半圆内部形成第二个更小的半圆
        → 停奶、抬升
Step 3: 重复 → 每个新半圆同心嵌套在前一个内部 → 直到杯子几乎满
Step 4: 最后一个半圆后 → 不做停顿 → 竖直抬升 → 拉细流划穿
```

**机械臂关键参数**:
- 每个半圆是独立动作段: {接近杯口 → 摇摆 → 前推 → 停止 → 抬高}
- 每层 Y 起始位置逐层后退 (杯近端方向)
- 每层 X 摆幅递减 (半圆越来越小)
- 层间停顿时间极短 (牛奶会分离)

### Rosetta (树叶) — 四步法

```
Step 1 "Create the Cloud":
  奶缸抵杯沿 → 杯远侧倒奶 → 同时稳定速度左右摆动
  关键: "中速"倒奶, 太慢则泡沫无法释出

Step 2 "Shake and Back":
  白色云出现后 → 保持摆动推至杯中心
  → 开始将奶缸稳定地往回拉
  关键: 摆动初在杯中心推, 靠倒奶速度将图案推向远端

Step 3 "Smaller Shakes":
  接近杯近端 → 逐渐减小摆动幅度
  → 直到形成小球或小心形
  关键: "让摇摆越来越小"

Step 4 "Lift and Swipe":
  杯几乎满 → 抬升奶缸 → 拉薄而稳定的奶流
  → 划穿波动中心线 → 完成叶脉
```

**机械臂关键参数**:
- Step 2 中"靠倒奶速度将图案推向远端"——**流速也参与图案推动**, 不仅是XY运动
- Step 3 "摆幅递减"——这是一个关键的 ramp-down 参数: `A(t) = A0 * (1 - t/T)`
- Step 4 划穿中心线——必须精确定位摆动轨迹的中心线

### 天鹅 (Swan) — 单次连续倒奶法

```
Step 1 "翅膀":
  在杯一侧制作 Rosetta → 区别: 不划穿罗塞塔中线
  → 奶流沿着罗塞塔一侧走 → 形成翅膀形状

Step 2 "身体":
  到达翅膀底部 → 停止前推 → 原地左右摆动(如做心形)
  → 保持小幅度摆动形成紧凑圆形身体
  → 同时稍微前推(类似郁金香推层)

Step 3 "脖子":
  身体完成后 → 停止摆动 → 将奶缸往自己方向拖
  → 形成脖子 → 到达杯顶时做 U 形下弯
  → 保持缸口贴近咖啡油脂面

Step 4 "头部":
  停住奶缸 → 左右摇摆形成小圆(迷你心形)
  → 抬升奶缸 → 拉细奶流 → 划穿小圆完成头部
```

**机械臂关键参数**:
- 最复杂的图案——四个阶段的轨迹参数完全不同
- 翅膀: Rosetta 轨迹(摆动+后移) + 侧向偏移
- 身体: 定点摆动(心形)
- 脖子: 停止摆动, 仅弧线拖动 + U 形弯
- 头部: 小圆(小振幅摆动) + 划穿

## 三、奶缸与杯子的空间关系

### 倒奶流量与倾斜角的关系

```
流速 = f(奶缸倾斜角, 奶缸中剩余奶量, 缸嘴形状)

  倾斜角越大 → 流速越大
  剩余奶量越少 → 同样倾斜角下流速越小
  窄尖嘴 → 流速更集中, 适合精细图案
  宽圆嘴 → 流速更分散, 适合大面积图案
```

### 奶缸嘴/把手对齐精度

> "the tiniest misalignment between where the handle points and where the jug spout points means your design won't point where you think it will"

**机械臂对应**: 末端执行器上奶缸的安装夹具需要精确标定缸嘴方向与 TCP (Tool Center Point) 的关系。

### 奶缸嘴在杯沿的"支点"作用

所有教程都强调: 奶缸嘴抵住/搭在杯沿上。这不仅是高度控制, 还提供了:
- **旋转支点**: 奶缸可以绕杯沿旋转, 产生自然的弧线运动
- **高度稳定**: 杯沿限制了最低高度
- **位置参考**: 杯沿作为触觉反馈

**机械臂对应**: 这个"支点约束"是机械臂最难模拟的。方案:
1. 在杯沿上加装力传感器 → 检测接触
2. 使用导纳控制 (admittance control) → 保持轻微接触力
3. 或使用高精度位置控制 → Z 轴保持在 0.5mm 公差内

## 四、流速与图案大小的关系

### 表面张力模型 (来自多个教程的综合)

```
空杯: 表面张力 = 0 → 奶泡可以自由流动
满杯: 表面张力 = MAX → 奶泡被压缩

结论:
  - 早开始作图 → 图案大 (表面张力低)
  - 晚开始作图 → 图案小、压缩 (表面张力高)
  - 作图过程中需持续增加流速 → 对抗逐渐增大的表面张力
```

### 流速与泡沫释出的关系

> Rosetta: "太慢则泡沫无法释出" (latteartguide)

这说明流量有一个**最低阈值**——低于此阈值, 奶泡会堵在缸嘴不出来。这也是为什么 Rosetta 需要"中速"倒奶。

> Clive Coffee: "保持恒定流量。流速过慢泡沫会堵在缸口, 过快则产生泡沫团块或溢出"

所以流速存在一个**最优窗口**:
```
V_min < V_optimal < V_max

V_min: 泡沫能顺畅流出缸嘴的最低流速
V_max: 泡沫不形成团块/不溢出的最高流速
```

## 五、摆动参数的精确模型 (综合各教程)

### 三种摆动的区别

| 图案 | 摆动特征 | 摆幅趋势 | 频率 | 叠加的平移 |
|------|---------|---------|------|-----------|
| 波纹心形 | 定点摆动 | 恒定 | 中 | 无平移 |
| 郁金香 | 分段定点摆动 | 逐层递减 | 中 | 逐层前推后停止 |
| Rosetta | 连续摆动 | 线性递减 | 中 | 匀速后移 |
| 天鹅身体 | 定点摆动 | 小幅度恒定 | 中 | 微前推 |

### Rosetta 摆动模型 (修正版)

基于 latteartguide 的 "Shake and Back + Smaller Shakes":

```
阶段 2a (推云): 
  X(t) = A * sin(2π * f * t), A 恒定
  Y(t) = 杯中心 (先不后移, "靠倒奶速度将图案推向远端")

阶段 2b (回拉 + 递减):
  X(t) = A(t) * sin(2π * f * t), A(t) = A0 * (1 - (t-t1)/T2)
  Y(t) = V_y * (t - t1), 向近端回拉

阶段 3 (收拢):
  X(t) = 继续递减 → 0
  Y(t) = 到达近端后停止

阶段 4 (划穿):
  Z 抬升 + XY 沿中心线划穿
```

## 七、拉花比赛评分标准参考 (WLAC)

来自 Perfect Daily Grind 2026年比赛报道:

- **2026 世界拉花冠军**: Bala (台湾), 总分 531 分
- 评分维度 (WLAC标准):
  - 视觉美感 / 图案复杂度
  - 对比度 (白色 vs 棕色)
  - 对称性
  - 图案在杯中的位置/比例
  - 难度系数
  - 整体印象
  - 制作时间

**机械臂启示**: 评分标准即优化目标——对比度 = 成形高度控制, 对称性 = X轴运动精度, 位置 = XY定位精度

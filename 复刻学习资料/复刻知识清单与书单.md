# 桃果采摘机器人项目 · 零基础复刻知识清单与参考书单

基于 aubo_e5_jazzy_ws 全部源码整理（ROS 2 Jazzy · AUBO E5 · Percipio/双目 RGB-D · 三把剪切手工具族）

**v2 · 2026 年 9 月 29 日**（v1 2026-09-08；本版同步并包重组、剪切手工具族、launch_testing 测试塔、peach_sim 感知矩阵、手眼标定包等三周演进）

**使用说明：** 本项目 = Python/C++ 两种语言 × ROS 2 Jazzy 通信框架 × 感知数学 × MoveIt 2 运动规划 × 安全分层。本文按六层知识结构组织，每层给出「项目里对应什么代码 → 需要掌握的知识点 → 推荐书籍/资源」，最后给出按依赖顺序的复刻路线图。配套的逐步导读见同目录《学习教程-基于本项目.md》。书籍以高质量、热门、有中文版者优先；ROS 2 / MoveIt 2 / ros2_control 三块以官方文档为主教材。

## 三、第 1 层：两门语言

### 3.1 Python 3.12（感知 + 调度 + 观测 + 仿真 + Web）

对应项目（并包重组后的现行路径，均在 `src/peach_harvester/peach_harvester/` 下）：

- pathlib、json 原子落盘（tmp+replace）、异常处理与日志分级、`yield` 生成器

### 3.2 C++17（机械臂技能包 `peach_arm`）

对应项目：`src/cycle.cpp`（动作受理+`authorizeStage` 授权矩阵）、`src/stages.cpp`（`executeCycle` 阶段序列显式 switch）、`src/grasp_task.cpp`（MTC 接触/套入/撤退装配）、`src/motion.cpp`（MoveIt 运动接口）、`src/target_cache.cpp`（三索引目标缓存）、`src/safety_gate.cpp` / `quality_gate.cpp` / `include/peach_arm/trajectory_guard.hpp`（纯函数护栏）、`std::atomic` 跨线程标志。

- RAII 与智能指针、const 正确性、明确的所有权（`unique_ptr` 回调接收大消息）
- std::optional / enum class / std::function / lambda 捕获陷阱（按值 vs 按引用）/ 移动语义
- std::atomic 与内存序（本项目只用 relaxed）、异常安全（回调内 catch→填 failure_code，不得冲出 spin）
- Executor 与回调组：MutuallyExclusive 死锁场景；重活进有界 worker

## 四、第 2 层：ROS 2 Jazzy（项目骨架）

对应项目：`peach_interfaces`（msg/srv/action IDL + `config/interface_manifest.yaml` 双向核对 + `scripts/check_interface_manifest.py`）；三能力节点走 Lifecycle 并由 nav2 `lifecycle_manager`（名 `peach_lifecycle_manager`）托管、bond 心跳接线；`harvest_system.launch.py`（include 链+防重复实例预检+工具档案参数注入）；TF 合法帧集以 URDF+单一 `extrinsics_publisher` 为准；双轨参数（Python=`peach_common.yaml_params.attach` 直读 yaml，C++=`generate_parameter_library`）；`peach_system_tests` 隔离域 launch_testing（工具三档域 91/92/93）。

- 节点/话题/服务/动作四种通信选型；QoS（RELIABLE vs BEST_EFFORT、transient_local 闩锁、兼容规则「RELIABLE 订户收不到 BEST_EFFORT 发布」）
- LifecycleNode：configure/activate/cleanup 与「非 Active 拒绝运动」纪律；bond 心跳=进程死则整栈降级
- TF2 三种查询策略：按时间戳精确（重建积分，失败跳帧）、latest 兜底（感知打 stale）、TimePointZero（技能规划）
- launch（Python OpaqueFunction、Include 不复制 bringup）、URDF/xacro（工具帧 `tcp.xacro` 参数化）、RViz、rosidl 自定义消息
- 参数纪律：禁止话题名当参数（相对名+remap）；启动期非法拒绝启动
- launch_testing：generate_test_description + ReadyToTest + post_shutdown_test；isolated `ROS_DOMAIN_ID`

## 五、第 3 层：感知数学（最难，书最齐）

对应项目：袋/果位姿管线（圆柱 RANSAC 定轴 + 球拟合+梗洼定向，`pose_pipelines.py`）；身份分配（世界系马氏距离 χ²≤9 门 + 匈牙利 1-1 + 类别 + 歧义比 1.2，`identity.py`）；EMA 平滑；有界 ICP（只修小刚性误差）；Open3D 在线 TSDF 积分（`integrate.py`）；手眼标定外参 `wrist3→camera_link`（`aubo_hand_eye_calibration` 包：Web 引导采集、`hand_eye/active.yaml` 事实源、`extrinsics_publisher` 单一发布）；视点基线角与停走式相机节拍；预抓取停位几何（`grasp_standoffs.yaml`，沿 −axis 后撤 0.03 m）；动态径向/轴向工具预算（`tool_budget.py`：套袋看 sleeve/径向余量，剪切看 cut/轴向余量+预抓取残差）→ `GraspDecision` 分档授权；`peach_sim` 合成场景感知验证矩阵（852 帧 GATE PASS 基线冻结）。

- 3D 刚体变换：旋转矩阵、四元数、齐次矩阵（SciPy Rotation 与 Eigen 两种实现；光学系 `*_optical` z 前 x 右 y 下，REP-103）
- 相机内参、像素投影与深度反投影；**深度是 uint16 毫米（产品例外，KEEP），边界处换米**；手眼标定 AX=XB 概念
- RANSAC、Huber 鲁棒拟合、最小二乘（scipy least_squares）
- ICP 点云配准、TSDF 体积积分、法线估计、下采样
- 匈牙利算法与马氏距离（χ² 门=3σ）；EMA 递推
- 多视角融合与模型七元组/revision 的新鲜度语义（`valid_until` 冻结不续签）

## 八、复刻路线图（按依赖顺序，跳过即卡壳）

1. **工具底座**：Python 基础 + colcon + git，把本仓构建起来、单包测试跑绿。
2. **ROS 2 通信**：话题/服务/动作/launch 四件套，写出 talker/listener；读懂 `peach_interfaces` 一个 IDL 的字段注释与 manifest。
3. **受管节点**：Lifecycle + 参数双轨 + TF2 三种查询策略，复刻一个最小受管节点（含 bond 心跳）。
4. **感知数学一**：《视觉SLAM十四讲》前 6 讲 + SciPy Rotation，复刻 `common/` 纯函数层（几何/EMA/拟合）。
5. **感知数学二**：Open3D，复刻点云构建、TSDF 体积、有界 ICP 纯核；理解身份分配 χ²+匈牙利。
6. **感知组装**：ultralytics YOLO+SAM 推理封装 → `message_filters` 同步 → 检测 → 分割 → 身份 → 锁定，组装场景感知节点。
7. **重建与决策**：多视角融合 refit + `tool_budget` 动态预算 → `GraspDecision` 分档；手眼标定概念与 `active.yaml` 链路。
8. **调度**：表驱动 FSM + reducer + 选果，组装调度节点（命令循环+账本+补采清单）。
9. **C++ 技能**：转 C++（Primer+Effective Modern 选读），复刻 MoveIt 2 规划壳 → MTC 接近 v4（PTP+垂直 LIN+沿轴 LIN）→ `authorizeStage` 授权门 → 轨迹护栏。
10. **工具族**：`tool_profiles` 三把剪切手档案注入链（yaml 单源→launch 注入→TF tcp 对齐）。
11. **硬件概念**：官方文档概念性复刻 ros2_control 透传（**真机驱动栈只读不抄，涉及安全**）。
12. **收口**：launch_testing 三档域 + 纯核测试塔 + 8090 观测 + lint + 活文档，整栈 mock 冒烟→campaign 式战役验证。

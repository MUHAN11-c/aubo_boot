# 基于本项目的复刻学习教程

以 aubo_e5_jazzy_ws（桃果采摘机器人：固定座 AUBO E5 + RGB-D + 三把剪切手工具族）的真实源码为教材，从零到整栈的渐进式学习路径。

**v1 · 2026 年 9 月 29 日**（配套《复刻知识清单与书单.md》v2；书单与获取渠道见《书单与正版获取渠道.md》）

---

## 0. 这份教程怎么用

### 0.1 学习哲学

- **代码即教材**：每个阶段都「先读本仓代码 → 再查官方文档印证 → 再动手」。孤立看书容易忘，绑定真实文件才会。
- **纯核先行**：本仓把业务逻辑写成零 ROS 纯核（不 import rclpy/rclcpp），节点只做接线。学习时优先读纯核——不需要起 ROS 就能读懂、能用 pytest 验证你的理解。
- **mock 自由、真机授权**：所有练习都在 `hardware_mode:=mock` 下进行，不起真机。真机相关只学概念与边界（S6/第 9 章）。
- **测完即停**：任何练习结束，`Ctrl+C` 停栈后必须 `pgrep -af 'ros2 launch|component_container|extrinsics_publisher|ros2 run'` 复核无残留（MUST 纪律，从第一天养成）。

### 0.2 前置环境

```bash
source /opt/ros/jazzy/setup.bash
cd ~/Desktop/aubo_e5_jazzy_ws
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
source install/setup.bash
```

Python 第三方在 venv（`aubo_py3.12`，numpy==1.26.4 硬约束）；ROS 依赖走 apt。

### 0.3 全栈鸟瞰（先记住这张图，后面每阶段填一块）

```
harvest_system.launch.py（peach_bringup，预检拒旧实例）
  aubo_e5_bringup            驱动只读；mock=GenericSystem+JTC
  serial_imu                 不进 lifecycle
  imu_follow_servo           仅 tool_profile=adaptive_shear_v1
  peach_harvester.brain      一进程三节点：
      peach_scene_perception_node      （L1 感知：一帧→观测）
      peach_target_reconstruction_node （L1 重建：多帧→模型+GraspDecision）
      peach_supervisor                 （调度：FSM/选果/账本）
  peach_arm                  C++ 技能：ExecuteTarget 阶段序列
  peach_observability        8090 观测 + 会话 bag（只读）
  peach_lifecycle_manager    nav2_lm 托管：场景→重建→技能→调度
```

数据单向（背下来，这是全仓最重要的不变量）：

```
RGB-D → 感知(事实) → 观测/初值
                 ↓
        重建(模型 + GraspDecision)
                 ↓
      调度(选果/FSM/账本) --ExecuteTarget/Survey--> 臂(运动)
                 ↑ CheckReachability 是唯一反向 IK 查询
```

禁止：感知发运动；技能写账本；调度把 `initial_pose`/`grasp_decision` 当选果源。

## S2 感知入门：一帧图像的旅程（≈2–3 周）

**目标**：读懂感知节点的八步管线；掌握图像同步、深度单位、质量门。

**教材**：动手学ROS2 通信与传感器篇；OpenCV 官方 Read/Display/Save；ultralytics 官方 Quickstart；`message_filters` 官方页。

**代码导读**（`src/peach_harvester/peach_harvester/vision/scene_perception/`，按此顺序）：

| 序 | 文件 | 看什么 |
|----|------|--------|
| 1 | `scene_perception_node.py` | Lifecycle 壳：订阅→decode→查 TF→发布，业务全在纯核 |
| 2 | `pipeline.py` | `process(SyncedRgbd) → PerceptionResult` 门面：八步的目录页 |
| 3 | `inference.py` | YOLO 检测去重 + MobileSAM 实例掩膜；无 SAM 时深度带连通域降级（须标 `mask_source`） |
| 4 | `pose_pipelines.py` | `RobustBagPosePipeline`（袋=圆柱 RANSAC 定轴）/`RobustFruitPosePipeline`（果=球拟合+梗洼定向） |
| 5 | `identity.py` | `TargetRegistry`：世界系 χ²≤9 门+匈牙利 1-1+类别+歧义比 1.2；`clear()` 不复位计数 |
| 6 | `image_gates.py` | 静止门/有效深度占比/贴边框不攒确认 |
| 7 | `msg_builders.py` | IDL 组装：观测怎么变成消息 |

八步口诀：**同步（slop 0.05s）→ 深度毫米裁前景 → 检测 → 分割 → 拟合位姿 → 单帧状态（ACCEPT/REOBSERVE/REJECT）→ 身份分配 → 锁定发布**。

**关键认知**：单帧状态只当初值/可视化，**不得据此接触**；TF 精确 stamp 失败则 `tf_status!='ok'`，不进身份链。

**动手练习**：

1. `colcon test --packages-select peach_harvester`，打开 `test/` 里感知纯核的表驱动用例，改一个断言看它怎么红。
2. 手算一次单位换算：Percipio 深度 uint16 值 850 → 0.85 m；写三行 numpy 完成掩膜反投影。
3. 读 `docs/io.md` 感知发布通道表，与 `msg_builders.py` 对读。

**过关判据**：能对着 `pipeline.py` 白板讲出八步，并说出「为什么贴边框不攒确认」。

## S3 感知数学：从像素到 GraspDecision（≈4 周，最难）

**目标**：掌握 3D 变换/拟合/ICP/TSDF/预算决策；这是全项目数学最重的一层。

**教材**：《视觉SLAM十四讲》第 2–6 讲（变换/李群李代数可略读）+ 第 7 讲（相机模型）+ 点云与 ICP 章；《现代机器人学》刚体运动章；SciPy `spatial.transform` 文档；Open3D 官方 ICP/TSDF 示例。

**代码导读**（`src/peach_harvester/peach_harvester/vision/`）：

1. `common/geometry.py`——纯函数几何层，先读懂这里的旋转/变换约定（体轴 x 前 y 左 z 上；光学系 z 前）
2. `target_reconstruction/reconstruction_core.py`——帧环/自动机/发布宿主：`ReconstructionSession` 会话态
3. `target_reconstruction/capture.py`——采帧门（IDLE/COLLECTING），停走式相机节拍
4. `target_reconstruction/integrate.py`——**锁外查 base←camera 精确时刻 TF**（失败跳帧，禁止运动中 latest）→ 质量门五道 `StrictMaskGate` → FK 到 base → 有界 ICP（只修小刚性误差）→ 在线 TSDF
5. `target_reconstruction/refine.py` + `refit_orchestrator.py`——finalize：抽网格+柱/球 refit 融合
6. `common/tool_budget.py`——**动态径向/轴向预算**：套袋看 `sleeve_capability`/`radial_margin_m>0`；剪切看 `cut_capability`/`axial_margin_m>0`+预抓取残差 → 汇成 `GraspDecision`
7. 手眼链路：`src/aubo_hand_eye_calibration/`（Web 引导采集，`hand_eye/active.yaml` 是外参事实源）→ 唯一发布者 `extrinsics_publisher` 发 `wrist3→camera_link`

**动手练习**：

1. 十四讲前 6 讲课后题选做一半；用 `scipy.spatial.transform.Rotation` 复算一次「光学系→体轴」旋转（z 前 x 右 y 下 → x 前 y 左 z 上）。
2. 手算身份门：两观测差向量的马氏距离平方=10.2，χ² 门=9，判匹配还是新建？（答：新建，超 3σ）
3. 读 `tool_budget.py` 的预算公式，代入 `aubo_description/config/adaptive_shear_v1.yaml` 的 `D_inner`/`L_insert`/`L_blade` 算一次径向/轴向余量的正负含义。
4. 用 Open3D 官方示例跑一遍 ICP，再回来看 `integrate.py` 的「有界」体现在哪（答案：限制单次修正幅度，只修小刚性误差，不吞大错）。

**过关判据**：能回答——重建为什么禁止 latest TF？`valid_until` 为什么冻结不续签？`GraspDecision.allowed` 与臂侧分档校验是什么关系（提示：allowed 只是汇总展示，强制点在臂侧 `authorizeStage`）？

## S4 调度与状态机：一批 RunHarvest 怎么跑（≈1–2 周）

**目标**：掌握表驱动 FSM、reducer、选果策略、批次策略与账本。

**教材**：《代码整洁之道》函数章（为什么表驱动优于 if 链）；本仓 `.agents/skills/peach/harvest-flow.md`（当讲义用）；launch 官方 action 章复习。

**代码导读**（`src/peach_harvester/peach_harvester/supervisor/`）：

1. `harvest_fsm.py`——`_TABLE` 事件→命令纯核表：先背「WAITING_READY+RUN_REQUESTED→DISCOVERY/NAVIGATE」这条主干，再读全表
2. `domain/reducer.py`——三维状态+世代/事务去重（重复事件不重放）
3. `executor_node.py`——命令循环：`reaction.command` 分发到 `_cmd_*` handler 表（NAVIGATE/SURVEY/BEGIN_SCENE/WAIT_LOCK/SELECT/DISPATCH/EXECUTE_FULL/NONE）
4. `batch.py`——`next_target` 选果：资格谓词（锁定/非裸果/不贴边）→ 深度∩可达窗 → `priority` 升序+检测框面积降序；超窗进 `targets_filtered`；跳过是策略不是失败（进 ReworkList）

## S5 C++ 与运动技能：ExecuteTarget 的阶段序列（≈4–6 周）

**目标**：读懂 C++ 技能包的受理门、授权矩阵、接近路径与护栏；这是 C++ 学习的主战场。

**教材**：《C++ Primer》智能指针/移动语义/并发三选读；《Effective Modern C++》对应条目（本文件夹《现代 C++ 教程》免费垫底）；MoveIt 2 官方 Getting Started+MTC+Pilz 三章；control.ros.org 概念章（只读学）。

**代码导读**（`src/peach_arm/src/`，按此顺序）：

1. `manipulation_skills_node.cpp`——Lifecycle 壳：订阅/发布/状态 JSON；MoveIt 伴随节点同 executor
2. `cycle.cpp`——动作受理门（非 Active/周期占用/`contact_recovery_required`→REJECT；模型七元组非空 presence-check）+ **`authorizeStage` 授权矩阵**：
   - TRANSIT/PREGRASP → `authorizeTransit`（使能×Active×robotReady×¬cancel）
   - CONTACT/TOOL → motionOutputAllowed + safetyReady + 令牌优先（`allowed`+target 绑定+`valid_until`+`model_stamp` 新鲜度）→ CONTACT 查 `radial_margin_m>0`；TOOL 再加 `axial_margin_m>0`+`pregrasp_verified`+`tool_enabled` → 无令牌回退快照
3. `stages.cpp`——`executeCycle` 阶段序列（当目录页背）：Prepare→(观察)→Finalize→(PREVIEW/READY 分岔)→Reconfirm→MovePregrasp→VerifyPregrasp→(PREGRASP_ONLY 停驻)→Sleeve→Cutter→VerifyCut→ReverseRetreat→Stow→Release→Complete
4. `grasp_task.cpp`——MTC 装配：接近 v4 主档（Pilz PTP 至冠外正下方→世界垂直 LIN 入冠→沿轴 LIN 进预抓取+20° OrientationConstraint）；套入=沿轴 LIN（shear/bite）或交 `imu_follow`（adaptive）
5. `motion.cpp` / `move_to.cpp`——MoveIt 接口、拍照位、enables 心跳
6. `target_cache.cpp`——selected/locked/refined/decision 三索引缓存
7. 纯核门：`safety_gate.cpp`、`quality_gate.cpp`、`include/peach_arm/trajectory_guard.hpp`（绕行累计 12 rad/单轴 6.1 rad 护栏）、`grasp_geometry.hpp`（果实胶囊仅接近段，套入/撤退豁免）
8. `config/peach_arm.yaml`——GPL 参数单源（对照 PickNik 文档）

**关键认知**：`execution_enabled` 时一次性 `execution_armed`，周期结束自动解除；8090 调试运动绕不过 `authorizeStage`；`ContactMonitor` 腕轴电流默认关，不是急停。

1. `colcon test --packages-select peach_arm`（gtest 已解禁，纯核门有单测）。
2. mock 起栈后在 RViz（MoveIt 已随栈起）看一次 PREVIEW 规划的可视化；对照 `docs/testing.md` 冒烟最小集。

## 9. 真机复刻的硬边界（不可越，先背再学）

1. **未授权不得真机运动或 SetIO**。授权=人的口头/书面确认=操作员在 real 上发起 launch/操作台指令；不是 yaml 里的某个 `true`，不是 8090 按钮。
2. **硬件急停不经 ROS**。示教器红钮/柜安全回路才是 ISO 13850 急停；一切软件停（`RobotMoveStop`/取消 action/8090）都只是应用层停轨。
3. **驱动九包只读**（hardware/controllers/dashboard/ros2_control.xacro/bringup/controllers.yaml）；bringup 不起 dashboard、不远程上电。
4. **测完即停**：任何测试/探针/bag/演示结束，停栈并 `pgrep` 复核，挂死按 PID 清。
5. 急停/保护停止后：先处理现场→示教器复位→取消丢弃在途 goal→重新授权下发；**禁止 resume 原轨迹**。
6. mock 通过只证明接线与使能门逻辑；碰撞、电流、急停回路、刀、人在环只在真机且需授权。
7. 关节序冻结：`shoulder_joint, upperArm_joint, foreArm_joint, wrist1_joint, wrist2_joint, wrist3_joint`，全链一致。
